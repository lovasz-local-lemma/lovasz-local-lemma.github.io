Theory

📐 Finite Element Method

Structures are discretized into triangular mesh elements. Each node has degrees of freedom (DOFs) representing displacement. The system is governed by the generalized eigenvalue problem:

K · φ = ω² · M · φ

where K is the stiffness matrix, M is the mass matrix, ω are the natural frequencies, and φ are the mode shapes.

🔊 Modal Synthesis

Each mode is an independent damped harmonic oscillator. The total displacement (and sound pressure) is the superposition of all modes:

p(t) = Σᵢ αᵢ · Aᵢ · e−ζωᵢ(t−t₀) · sin(ωd,ᵢ · (t−t₀))

This closed-form solution is evaluated on GPU via CUDA — one thread per audio sample, all modes summed in parallel. 44.1kHz, 512-sample buffer, zero-latency analytical evaluation.

Visualization

🌊 Medium Propagation

Acoustic radiation visualized in real-time using a Kirchhoff boundary integral evaluated on GPU via OpenGL compute shader:

p(x,t) = Σⱼ vn,ⱼ · sin(ω(t − rⱼ/c)) / √rⱼ · cos(θⱼ)

Each boundary node acts as a point source with retarded time. The compute shader evaluates this at every pixel (up to 1920×1080), with per-pixel point-in-mesh occlusion testing.

Features

  • ✦ Pixel-perfect resolution
  • ✦ Deformed mesh mask (follows vibration)
  • ✦ Directional radiation (cos θ weighting)
  • ✦ Blue/red phase coloring with exposure control

Acoustic Feedback

Optional medium→structure coupling: pressure at each boundary node from other sources is computed and applied as force, enabling sympathetic resonance between separate structures through the air.

Roadmap

🚀 Future Directions

Near-term

3D Solid Elements — Tetrahedral FEM for volumetric vibration. Requires 3D mesher (TetGen) and 3D rendering.

Near-term

Per-Mode Damping — Frequency-dependent damping instead of uniform ζ. Higher modes decay faster (material-accurate).

Medium-term

Tension-Based Strings — Wave equation elements (f ∝ 1/L) instead of beam bending (f ∝ 1/L²) for realistic string sound.

Medium-term

Convolution Reverb — Room impulse response applied post-synthesis for spatial realism.

Long-term

BEM Acoustic Radiation — Full Boundary Element Method replacing the simplified Kirchhoff integral for accurate far-field radiation patterns.

Long-term

Multi-Material Regions — Per-element material properties for composite structures (wood body + steel strings + brass frets).

Modal Synthesis — Built with C++, CUDA, OpenGL, and physics.
