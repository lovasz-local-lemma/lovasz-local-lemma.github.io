Modal2D — Technical Overview

Real-time modal sound synthesis from FEM eigenanalysis of 2D shapes, shells, and 3D solids

Modal2D is an interactive physically-based sound-synthesis system that turns a drawn shape, a curved shell, or a parametric 3D solid into a vibrating object you can strike, bow, and hear. It discretizes the geometry with low-order finite elements, assembles the global stiffness and mass matrices $K,M$, solves the generalized symmetric eigenproblem $K\phi=\omega^2 M\phi$ for the lowest few-dozen modes, and renders each mode as a decaying modal oscillator summed in real time on the GPU.

The goal is a tight design-and-listen loop: sketch or pick a shape, perforate or curve it, strike it, hear a physically-grounded timbre, and even auto-tune its geometry so a struck partial lands on a chromatic target. The system is split into libmodal — a reusable C++/CUDA FEM & modal-synthesis engine exposing a C-style API over opaque handles — and modal_viewer, a Dear ImGui / GLFW / OpenGL desktop application with a PortAudio backend that consumes only that API and adds rendering, input, the post-processing DSP chain, and the inverse-design tuning search. This document presents the engine end-to-end for an expert graphics / audio / numerical-methods reader, with the implementing files and functions cited inline.

Modal2D is the standard discretize-then-diagonalize modal-sound pipeline (van den Doel/Pai; O'Brien et al.) factored into a clean engine/application split. The boundary is drawn at the level of opaque modal results: libmodal forward-declares handle types ModalObject and ModalResult and exposes only free functions over pointers to them, so the viewer never sees a stiffness matrix, an eigenvector layout, or a device pointer through the public header — only modal_create_*, modal_solve, modal_strike, modal_get_displacements, modal_fill_audio, and read-only query functions.

The engine computes eigenpairs $(\omega_i,\phi_i)$ once per geometry, augments them at solve time with per-mode damping ratios and radiation coefficients, then evaluates a bank of damped oscillators

$$q_i(t)=\sum_k A_{i,k}\,e^{-\zeta_i\omega_i (t-t_{0,i,k})}\sin\!\big(\omega_{d,i}(t-t_{0,i,k})\big),\qquad \omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2}.$$

A strike projects an impulse onto the mass-orthonormal modal basis via the boundary-normal-weighted mode value at the strike point; the per-mode, per-slot excitation amplitudes feed a CUDA synthesis kernel that produces a 44.1 kHz PCM stream, post-processed by the viewer's PortAudio callback. The same modal state drives the animated mode-shape visualization and the spectral-analysis panels, so synthesis sits at the junction of audio output and visual feedback. The GPU is used in two unrelated ways: CUDA inside libmodal (a cuSOLVER dense generalized eigensolver and a per-sample audio-synthesis kernel) and OpenGL inside the viewer (mesh shaders plus a GLSL compute shader that paints a heuristic radiated-pressure field). On top of the forward pipeline sits an inverse-design outer loop: each tuning iteration remeshes, re-solves, reads back the modal spectrum, and proposes new geometric parameters until a struck partial matches a chromatic target.

System architecture, GPU & external libraries

Modal2D is split into a reusable FEM/modal-synthesis engine (libmodal, a static library modal_lib exposing a namespace modal C-style API over opaque handles in modal/modal.h) and a GUI application (modal_viewer, an OpenGL 4.5 core / Dear ImGui desktop app) that consumes only that API. Theory

The engine/app boundary as a contract

The boundary is drawn at the level of opaque modal results. libmodal forward-declares handle types ModalObject and ModalResult (modal/types.h:144) plus free functions over pointers to them; the concrete struct ModalObject / struct ModalResult are private (modal_api.cpp:34 and :152). The viewer never sees a stiffness matrix, an eigenvector layout, or a device pointer through the public header — only modal_create_*, modal_solve, modal_strike, modal_get_displacements, modal_fill_audio, and read-only query functions. This is the standard modal sound-synthesis pipeline (van den Doel/Pai; O'Brien et al.) factored into a library:

$$K\phi_i = \omega_i^2 M\phi_i,\qquad q_i(t)=\sum_k A_{i,k}\,e^{-\zeta_i\omega_i (t-t_{0,i,k})}\sin\!\big(\omega_{d,i}(t-t_{0,i,k})\big),\quad \omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2}.$$

The engine computes eigenpairs $(\omega_i,\phi_i)$ once per geometry (modal_solve), then evaluates a bank of damped oscillators. A strike projects an impulse onto the modal basis via the boundary-normal-weighted mode value at the strike point: compute_strike_impulse builds $f_{\text{impulse}}$, then project_strike (oscillator.cu:15) sets the per-mode, per-slot excitation $A_{i,k}=f_{\text{impulse},i}\cdot\text{magnitude}$ (clamped to $\pm 50$, with a $|A|<0.005$ dead-zone).

Per-mode damping and radiation weighting (implemented, beyond the textbook model)

Two details make the synthesis richer than a bare modal sum. Damping is per-mode and frequency-dependent:

$$\zeta_i=\zeta_0+\text{slope}\cdot\frac{\omega_i}{2\pi\cdot 1000}$$

(modal_api.cpp:162, materialized into mode_zetas at :2838-2846 / :3299-3308 and uploaded to d_zetas), so high overtones decay faster. Each mode also carries a scalar radiation coefficient $\alpha_i$ from a discrete monopole boundary integral (radiation.h, compute_radiation_coefficients):

$$\alpha_i=\rho_{\text{medium}}\,\omega_i\sum_{j\in\partial\Omega}\phi_{i,n,j}\,A_j,\qquad \max_i|\alpha_i|=1,$$

where $\phi_{i,n,j}$ is the outward-normal displacement of mode $i$ at boundary node $j$ and $A_j$ the node's boundary-segment half-length. $\alpha_i$ scales each mode's contribution to the output sample, so poorly-radiating modes are attenuated in the audio.

Where the GPU enters

Two numerically heavy steps map to data-parallel hardware:

  1. The generalized symmetric eigenproblem $K\phi=\lambda M\phi$. For small systems the engine forms dense single-precision $K,M$ (column-major, lower-triangular) and calls cuSOLVER's $\texttt{Ssygvdx}$ with CUSOLVER_EIG_RANGE_I, index range $[1,\min(n,m{+}3)]$, returning the lowest eigenpairs of a symmetric-definite pencil with the eigenvectors overwriting $d\_K$. Frequencies are $\omega_i=\sqrt{\lambda_i}$, with a rigid-body filter dropping $\omega_i<\texttt{rigid\_threshold}$.
  2. Audio synthesis, embarrassingly parallel over output samples. One CUDA thread per PCM sample $s$ computes $t=t_{\text{start}}+s\,\Delta t$ and the radiation-weighted modal sum, with a global pitch multiplier freq_shift:
$$p(s)=\sum_{i} \alpha_i\sum_{k=0}^{K-1} A_{i,k}\,e^{-\zeta_i\omega_i'\,\delta}\sin(\omega_{d,i}\,\delta),\quad \omega_i'=\omega_i\cdot\texttt{freq\_shift},\ \delta=t-t_{0,i,k}>0,$$

where $K=\texttt{STRIKE\_RING\_SIZE}$ is the per-mode strike ring (audio_sum_kernel, synthesis.cu:24-66; $p$ is finite-guarded). For $M$ modes and a 512-sample buffer this is $\approx 512\cdot M\cdot K$ transcendental evaluations per callback in one launch.

The viewer's GPU work is graphics, not solve. The deformed mesh is drawn by passing per-node 2D displacement $\mathbf{u}_i(t)$ as a vertex attribute; the radiated field is a per-pixel heuristic Kirchhoff-style sum over (decimated) deforming boundary sources:

$$p(\mathbf{x},t)\;\approx\!\!\sum_{j\in\partial\Omega,\,\text{step}} v_{n,j}\,\sin\!\big(\omega_{0}(t-r_j/c)\big)\,\frac{\cos\theta_j}{0.5+3\sqrt{r_j}},\qquad r_j=\lVert\mathbf{x}-\mathbf{x}_j\rVert,$$

with $v_{n,j}$ the boundary node's outward-normal velocity, $\omega_0$ the lowest modal frequency (freqs[0], used as a single dominant tone), $\theta_j$ the source-to-pixel angle vs. the outward normal ($\cos\theta_j<0\Rightarrow$ skip, a half-space cull), source stride $\texttt{src\_step}=\max(1,n_b/60)$, and $c=343\,\text{m/s}$ hardcoded. The $1/(0.5+3\sqrt r)$ falloff is ad-hoc. This is a real-time visual cartoon, not a coupled BEM solve, and does not feed back into audio.

Per-frame data flow

App::run (app.cpp:8736) is glfwPollEvents → process_input → render. Each App::render (app.cpp:1113): (a) advances a slow-motion-scalable clock; (b) polls the background SolveWorker and swaps in a new ModalResult if ready; (c) reads animated displacements (modal_get_displacements, app.cpp:1496) and uploads them to the displacement VBO (cuda_gl_buf_.write_displacements, :1563); (d) runs the mesh GL block (wireframe/filled shaders) before ui_.begin_frame() (:1778, which calls ImGui::NewFrame); (e) enters the ImGui phase, where it draws panels/overlays AND calls draw_medium_propagation() (:4986) — this dispatches the medium compute shader and blits its texture via ImGui's background draw list, so the compute step lives in the ImGui phase, not the pre-NewFrame block; (f) glfwSwapBuffers (:5462). Audio runs on a separate PortAudio callback thread (pa_callback) that calls modal_fill_audio, which drains the strike buffer, projects strikes under a mutex, uploads the updated $(A,t_0)$ ring arrays, and launches the synthesis kernel.

GPU / CUDA usage (engine side)

  • Dense eigensolve on GPU — eigensolve_dense.cu:solve_dense. Converts Eigen sparse double K,M to column-major dense float (lower triangle), then cusolverDnSsygvdx_bufferSize + cusolverDnSsygvdx with CUSOLVER_EIG_TYPE_1, CUSOLVER_EIG_MODE_VECTOR, CUSOLVER_EIG_RANGE_I, CUBLAS_FILL_MODE_LOWER, $iu=\min(n,\,\texttt{num\_modes}+3)$. Eigenvectors come back in overwritten d_K; nonzero info throws.
  • Dispatch — eigensolve.cpp:solve_eigenmodes: K.rows() <= DENSE_DOF_THRESHOLD (512) goes to the GPU dense path inside a try/catch; on exception (documented as float32 Cholesky failing on FINE meshes) or for larger meshes it falls back to solve_sparse. A per-component block solve solve_eigenmodes_per_component extracts each connected component's K/M sub-blocks, solves them independently, scatters eigenvectors to full length, and merges by ascending frequency.
  • CPU sparse fallback — eigensolve_sparse.cpp:solve_sparse: a hand-rolled shift-invert Lanczos for the generalized pencil (no ARPACK/Spectra). It regularizes zero-stiffness/zero-mass DOFs, factors $K-\sigma M$ with Eigen::SimplicialLDLT (from <Eigen/SparseCholesky>) at $\sigma=10^{-4}$, runs the M-orthonormal Lanczos recurrence with full reorthogonalization from a fixed-seed (mt19937(42)) start vector, then maps Ritz values via $\lambda=1/\mu+\sigma$.
  • CUDA audio synthesis — synthesis.cu. SynthesisState (audio/synthesis.h) holds device arrays d_freqs/d_zetas/d_amps/d_onset/d_alphas/d_pcm, pinned h_pcm, and a dedicated cudaStream_t. audio_sum_kernel is one thread per sample (block=256) summing $\alpha_i\,A\,e^{-\zeta\omega'\,\delta}\sin(\omega_d\,\delta)$ over modes × STRIKE_RING_SIZE with freq_shift and finite-guarding. synth_fill launches on the stream, cudaMemcpyAsyncs to pinned memory, syncs, copies out (capped at 512 samples). A CPU mirror (oscillator.cu:eval_modes_cpu/eval_single_mode) serves the visual path and tests.
  • GPU strike upload — modal_api.cpp:modal_fill_audio (:3839) drains strikes, calls project_strike under mode_states_mutex, then cudaMemcpyAsyncs the rebuilt $(A,t_0)$ rings into d_amps/d_onset before synth_fill. Radiation coefficients are computed at solve time (:3225 via compute_radiation_coefficients) and uploaded to d_alphas (:3324-3328).

GPU usage (viewer side)

  • Mesh rendering — inline GLSL 450-core shaders in App::init_gl (app.cpp:192): a wireframe shader (reads vec2 aPos,vec2 aDisp, applies zoom/pan/aspect) and a filled shader with heat/Chladni colormaps, plus separate 3D shaders. Data flow plumbing

  • Background solving — app/solve_worker.{h,cpp}: start spawns a std::thread running modal_solve; App::render polls is_done() (acquire) and calls take_result(), with documented release/acquire ordering on done_.

Pipeline role

This section is the structural spine the other sections hang on, spanning the whole pipeline: shape/mesh (Triangle + triangulator in libmodal) → K/M assembly (Eigen, CPU) → eigensolve (cuSOLVER Ssygvdx dense on GPU for ≤512 DOFs, hand-rolled Eigen shift-invert Lanczos CPU fallback) → modes + per-mode $\zeta_i$ + radiation $\alpha_i$ stored in opaque ModalResult → strike projection (CPU, mutex-guarded) → audio synthesis (CUDA kernel on a PortAudio thread) and visualization (OpenGL mesh shaders pre-NewFrame; GLSL medium compute + ImGui overlays in the ImGui phase). It defines who owns what (engine vs app), how data crosses the C-API (opaque handles + POD query buffers), which work runs on the GPU (eigensolve + audio in CUDA; mesh + medium field in OpenGL), and which libraries provide each capability.

Meshing & geometry

Modal2D builds three families of computational domains: (1) 2D planar meshes of arbitrary simple polygons and preset outlines, triangulated by Shewchuk's Triangle library (constrained, quality Delaunay refinement) with an optional pre-seeded crystal-lattice path; (2) the same 2D footprint lifted into a curved shallow shell via a closed-form per-node height field $z(x,y)$ consumed by a Marguerre shallow-shell FEM assembler; and (3) structured tetrahedral meshes of parametric 3D solids (cube, sphere/ellipsoid, cylinder, cone, pyramid, capsule, torus). Porosity is supported in two of the three families: 2D plates via Triangle's hole-list (scatter_holes + triangulate_with_holes), and 3D solids via straight Z-tunnel carving of the tet set; the 2D-shell path does not carve porosity (the shell solve uses the solid mesh footprint). All generators are deterministic so a given shape/seed always produces the same mesh.
Theory

2D triangulation: constrained, quality Delaunay

The 2D mesher solves a planar straight-line graph (PSLG) triangulation problem: given a simple polygon boundary $\partial\Omega$ (and optionally interior hole loops), produce a triangulation $\mathcal{T}$ of $\Omega$ that is conforming, respects the input segments as constrained edges, and satisfies quality bounds. Triangle implements Ruppert's Delaunay refinement: starting from the constrained Delaunay triangulation (CDT) of the PSLG, it inserts circumcenters ("Steiner points") to eliminate (a) triangles whose minimum angle falls below a bound and (b) triangles exceeding a maximum-area constraint $A_{\max}$. The empty-circumcircle (Delaunay) property

$$\forall T\in\mathcal{T},\ \nexists\, p\in V:\ p\in \mathrm{int}\big(\mathrm{circ}(T)\big)$$

maximizes the minimum angle over all triangulations of a fixed point set, which directly benefits the conditioning of the downstream FEM mass/stiffness matrices (well-shaped CST/DKT triangles avoid ill-conditioned element Jacobians). In this code the quality+area switches are pqzea<A>Q: q = quality (Triangle's default $\sim$20$^\circ$ minimum-angle bound), a<A> = per-triangle area cap, p = PSLG, z = zero-indexing, e = emit edge list (used to recover boundary loops). The area cap $A_{\max}$ is the only resolution knob, mapped per level COARSE$\to$EXTREME as $A_{\max}\in\{0.02,\,0.005,\,0.002,\,0.001,\,3\times10^{-4},\,1\times10^{-4}\}$ (m$^2$). Since $A_{\max}\sim \ell^2$, characteristic edge length scales as $\ell\sim\sqrt{A_{\max}}$ and node count as $N\sim |\Omega|/A_{\max}$.

Crystal-lattice (non-Delaunay) interior seeding

An alternative path bypasses Ruppert refinement: interior nodes are placed on a regular grid first, then Triangle is invoked with pzYeQ (no q, no a) so it only computes the CDT of the supplied points (the Y flag preserves segment endpoints so the polygon boundary survives intact). For a square lattice of pitch $s$, points sit at $(x_{\min}+\tfrac{s}{2}+is,\ y_{\min}+\tfrac{s}{2}+js)$; for the triangular/hexagonal lattice (these two enum values share one code path), rows are offset by $s/2$ on alternate rows with row pitch $\Delta y = s\sqrt3/2$ (the equilateral-triangle grid, also the vertex set of the honeycomb). The "graphite" lattice keeps rows regular in $y$ but jitters $x$ by $\pm s/3$ (a deterministic LCG, not seeded by the porosity seed) to mimic anisotropic microstructure. Lattice pitch is $s=\sqrt{A_{\max}}$ (res_to_spacing). Points are kept only if the candidate and its four $\pm$margin axis-neighbors (margin $0.4s$) lie strictly inside $\Omega$ (ray-casting point-in-polygon), preventing slivery boundary triangles. This trades Delaunay angle-optimality for near-regular connectivity, yielding cleaner, more isotropic modal node patterns. Glass (= pure Delaunay) and Pentagon both fall back to the refined Delaunay path (Pentagon has no lattice generator).

Porosity: hole-list carving (2D)

Voids are circular disks $\{(c_x,c_y,r)\}$ scattered to approximate a target void fraction $\phi$ (clamped to $[0,0.35]$). The placement is rejection sampling against three constraints — interior containment, boundary clearance $d_{\partial\Omega}(c)\ge r+m$, and mutual non-overlap $\lVert c_i-c_j\rVert \ge r_i+r_j+m$ with margin $m=0.4\,r_0$ — accumulating area $\sum \pi r_i^2$ until it reaches $\phi\,|\Omega|$ or a 4000-attempt cap. The mean radius is $r_0=\texttt{hole\_size}\cdot\min(L_x,L_y)$ where $\min(L_x,L_y)$ is the smaller bbox extent, each radius jittered $\times U(0.75,1.25)$, drawn from a seeded std::mt19937 for reproducibility. Each accepted disk becomes a closed segment loop wound clockwise (16 segments) plus an interior hole-marker point; Triangle's flood-fill from the marker deletes the enclosed triangles, leaving a perforated-but-connected ligament network whose effective stiffness (and hence modal spectrum) drops with $\phi$.

Shell curvature: Marguerre shallow-shell height field

A flat 2D footprint is turned into a shallow shell by attaching a known mid-surface height $z=f(x,y)$ at every node (closed forms in compute_z_at). With reference radius $R=\tfrac12\min(L_x,L_y)$ and depth $h=0.3\,a\,R$ (amount $a\in[0,1]$), the kinds are:

$$ \begin{aligned} \text{Dome}&: z=h\,\max\!\big(0,\,1-r^2/R^2\big), & \text{Cone}&: z=h\,\max\!\big(0,\,1-r/R\big),\\ \text{Cylinder}&: z=h\cos(\pi y/L_y), & \text{Saddle}&: z=h\,(x^2-y^2)/(L_xL_y),\\ \text{Bowl}&: z=h\,(r^2/R^2)^2, & \text{Flat}&: z=0, \end{aligned} $$

with $r^2=x^2+y^2$ and $(x,y)$ centered at the bbox origin (the shell solve subtracts the bbox center before calling compute_z_at). This $z$-field is the geometric input to Marguerre's shallow-shell theory, which augments the in-plane (membrane) strain with curvature-coupling terms. For linearly interpolated $z$ over a CST triangle, $\partial_x z,\partial_y z$ are element-constant and the membrane strain acquires

$$ \varepsilon_{xx}\!\mathrel{+}=\!(\partial_x z)(\partial_x w),\quad \varepsilon_{yy}\!\mathrel{+}=\!(\partial_y z)(\partial_y w),\quad \gamma_{xy}\!\mathrel{+}=\!(\partial_x z)(\partial_y w)+(\partial_y z)(\partial_x w), $$

the small-amplitude (linearized von Kármán) limit. This couples bending $w$ to stretching, so the assembled $K\phi=\omega^2 M\phi$ has membrane–bending blocks that stiffen flexural modes — geometric stiffening that distinguishes a gong/bowl from a flat plate. The code emits both the cross-coupling block $K_{mb}$ and an extra positive-definite bending block $K_{bb,\text{extra}}=G_w^{\top}(S_z^{\top}D_m S_z)G_w\,A$ that guarantees curvature raises (never lowers) flexural frequencies. At $z\equiv0$ all coupling vanishes and the shell solve reduces exactly to the flat plate.

3D structured tetrahedral meshing

Solids are meshed without a 3D Delaunay tessellator. A cube is a regular $n^3$ grid split into 6 tets per voxel by the Freudenthal/Kuhn subdivision (six tets sharing the cube main diagonal, guaranteeing face-conformity across cells; explicit tetc table). Spheres/ellipsoids reuse the cube grid and apply the $L^\infty\!\to\!L^2$ shell map $\mathbf{p}\mapsto \mathbf{p}\,\lVert\mathbf{p}\rVert_\infty/\lVert\mathbf{p}\rVert_2$ (maps cube shells to concentric spheres), then per-axis scaling (ELLIPSOID uses $(1,0.7,1.3)$). Bodies of revolution/extrusion (cylinder, cone, pyramid, capsule, torus) stack scaled copies of a 2D base cross-section (a Triangle-meshed disc or a structured square grid) into prism layers, each base-triangle prism split into 3 tets. Winding is normalized to positive signed volume $\tfrac16\det[\,\mathbf{b}-\mathbf{a},\mathbf{c}-\mathbf{a},\mathbf{d}-\mathbf{a}\,]>0$ (push_tet). The boundary surface is extracted combinatorially: a triangular face shared by exactly one tet is a boundary face, oriented outward by the sign of $\mathbf{n}\cdot(\mathbf{x}_{\text{opp}}-\mathbf{x}_A)$. 3D porosity drills straight Z-tunnels by deleting tets whose XY centroid lands in a scattered disk, then keeps only the largest face-connected component (so the free-solid 6-rigid-body-mode invariant is preserved), reverting the whole carve if it would lose $>50\%$ of the tets.

Pipeline role

This is the SHAPE→MESH stage, the front of the end-to-end pipeline. A preset/polygon outline (or a parametric solid kind) is converted into a concrete discretization: 2D nodes+triangles (Mesh), an optional per-node z-height field for shells, or 3D nodes+tets+surface (SolidMesh). That discretization is the direct input to the ASSEMBLE stage (CST+DKT/Mindlin plate, Marguerre shell, or tet assemblers build sparse K and M), which feeds the EIGENSOLVE ($K\phi=\omega^2 M\phi$ → modes), then strike projection / modal synthesis / audio, with the same mesh reused for the renderer's animated mode-shape and curvature visualization. Mesh resolution and porosity here set both the spectral accuracy and the qualitative timbre (perforation lowers stiffness and detunes the spectrum).

FEM element formulations

libmodal builds the global stiffness $K$ and mass $M$ for a generalized eigenproblem $K\phi=\omega^2 M\phi$ from a small zoo of low-order triangular / tetrahedral / line elements, each in its own element_*.cpp (kernels in libmodal/src/fem/) and scattered by a matching assembler_*.cpp. The structural members are: a constant-strain plane-stress triangle (CST, with an orthotropic variant), a thin-plate bending triangle that evaluates the Batoz (1980) DKT rotation-interpolation functions to form a curvature-$B$ operator, a Mindlin-Reissner thick-plate triangle (constant-curvature bending + linearly interpolated transverse shear with Lyly-Stenberg-Vihinen stabilization), a Marguerre shallow-shell triangle that composes the CST membrane + DKT/Mindlin bending plus a bending-stretching coupling block, a linear 4-node tetrahedral 3D solid, and a 2D Euler-Bernoulli beam (with geometric pre-tension stiffness) for strings. A separate P1 scalar-Laplacian "acoustic" triangle handles air cavities. All structural elements use an isotropic linear-elastic constitutive law parameterized by $(E,\nu,\rho)$ from MaterialParams (orthotropy is wired only into the CST membrane).
Theory

All structural elements share the small-strain linear-elastic weak form. For a domain $\Omega$ with displacement $u$, strain $\varepsilon$, stress $\sigma=D\varepsilon$ and density $\rho$, the Galerkin discretization $u\approx N u_e$ gives the element matrices

$$K_e=\int_{\Omega_e} B^\top D\, B\,dV,\qquad M_e=\int_{\Omega_e}\rho\, N^\top N\,dV,$$

with $B=\partial N$ the strain-displacement operator. Assembling all $K_e,M_e$ and substituting $u(x,t)=\phi\,e^{i\omega t}$ into $M\ddot u+Ku=0$ yields the generalized symmetric eigenproblem $K\phi=\omega^2 M\phi$ solved downstream (solve_eigenmodes, eigensolve.cpp). The solver dispatches on size: for $\mathrm{DOF}\le 512$ it calls a dense GPU path (solve_dense, eigensolve_dense.cu, single-precision cusolverDnSsygvdx with CUSOLVER_EIG_TYPE_1, lower fill, range-I lowest indices), falling back on exception to a hand-written sparse path (solve_sparse, eigensolve_sparse.cpp — a single-vector thick-restart Lanczos with shift-invert $\sigma=10^{-4}$ factorized by Eigen SimplicialLDLT; explicitly not ARPACK/Spectra). Presets are typically free-free, so $K$ is singular with rigid-body modes that both solvers filter by $\omega<$ rigid_threshold; Dirichlet rows are eliminated only when fix_level>0 or explicit fixed_nodes are set (modal_api.cpp).

1. CST membrane / plane stress (cst_element_matrices)

Governing PDE: 2D Navier elasticity $\nabla\!\cdot\sigma=\rho\ddot u$ with plane-stress reduction. Linear shape functions $N_i=L_i$ (area coordinates) make $\varepsilon$ constant per element. With node-cyclic coefficients $b_i=y_j-y_k$, $c_i=x_k-x_j$ and area $A$,

$$B=\frac{1}{2A}\begin{bmatrix}b_1&0&b_2&0&b_3&0\\0&c_1&0&c_2&0&c_3\\c_1&b_1&c_2&b_2&c_3&b_3\end{bmatrix},\quad D=\frac{E}{1-\nu^2}\begin{bmatrix}1&\nu&0\\\nu&1&0\\0&0&\tfrac{1-\nu}{2}\end{bmatrix}.$$

$K_e=tA\,B^\top D B$ (closed-form, single point — $B$ is constant). The mass is the consistent CST mass $M_e=\frac{\rho t A}{12}$ with the value $2$ on each node-self $2\times2$ diagonal block and $1$ on the off-diagonal blocks (block-diagonal in $x,y$). The orthotropic variant (cst_element_matrices_ortho) builds the plane-stress $D_{\text{principal}}$ from $(E_x,E_y,G_{xy},\nu_{xy})$ with $\nu_{yx}=\nu_{xy}E_y/E_x$, $Q_{11}=E_x/(1-\nu_{xy}\nu_{yx})$, $Q_{12}=\nu_{xy}E_y/(1-\nu_{xy}\nu_{yx})$, $Q_{22}=E_y/(1-\nu_{xy}\nu_{yx})$, $Q_{33}=G_{xy}$, then rotates it to the element frame by a Voigt strain transformation $D_{\text{local}}=T_m^\top D_{\text{principal}} T_m$ (with $T_m=T(-\theta)$).

2. DKT thin-plate bending (dkt_element_matrices)

Governing PDE: Kirchhoff biharmonic $D_b\nabla^4 w=\rho h\,\ddot w$ with $D_b=Eh^3/12(1-\nu^2)$. DOFs $(w,\theta_x,\theta_y)$. The kernel evaluates the Batoz (1980) DKT rotation-interpolation functions $H^x_k(L_1,L_2,L_3)$, $H^y_k$ (the in-file Hx[9],Hy[9]) with edge constants $P_k=-6a_k/\ell_k^2$, $q_k=3a_kb_k/\ell_k^2$, $r_k=3b_k^2/\ell_k^2$, $t_k=-6b_k/\ell_k^2$ (here $a_k,b_k$ are edge $x,y$ differences and $\ell_k^2$ the edge length squared). The curvature $\kappa=(\kappa_{xx},\kappa_{yy},2\kappa_{xy})=B u$ is assembled by analytic chain-rule differentiation of $H^x,H^y$ through the area coordinates (the $H$ are linear in $L_1,L_2,L_3$, so $d/dx,d/dy$ replace $L_i\to dL_i/dx,\,dL_i/dy$), accumulated at the 3-point interior Gauss rule (weights $1/3$):

$$K_e=\sum_{q}A\,w_q\,B(\xi_q)^\top D_b\, B(\xi_q),\quad D_b=D_b\!\begin{bmatrix}1&\nu&0\\\nu&1&0\\0&0&\tfrac{1-\nu}{2}\end{bmatrix}.$$

Mass is lumped: $\rho h A/3$ on each $w$ DOF and a rotary inertia $\rho h^3 A/36$ on each rotation DOF. Note $\nu$ is hardcoded to $0.3$ inside the bending $D_b$ (the scalar prefactor $D_b$ passed in does carry the true $\nu$, but the $[1,\nu;\nu,1;\dots]$ shape matrix uses $0.3$). The file's top comment misleadingly labels the element "BCIZ" / "Tocher"; the code that actually runs uses the Batoz $H^x/H^y$.

3. Mindlin-Reissner thick plate (mindlin_element_matrices)

Adds first-order transverse shear: $K_e=K_{\text{bend}}+K_{\text{shear}}$. Bending uses linear rotations $\Rightarrow$ constant curvature $B_b$, with $\kappa_{xx}=\sum b_i\theta_{y,i}$, $\kappa_{yy}=-\sum c_i\theta_{x,i}$, $\kappa_{xy}=\sum(c_i\theta_{y,i}-b_i\theta_{x,i})$ (here $b_i,c_i$ are the area-coordinate gradients $dL_i/dx,\,dL_i/dy$). The shear strain $\gamma=\nabla w+\beta$ (with $\beta_x=\theta_y$, $\beta_y=-\theta_x$) uses the linear $w$-gradient plus rotations interpolated by $N_i=L_i$, integrated at 3 Gauss points. Shear locking is suppressed by the Lyly-Stenberg-Vihinen factor:

$$D_s=\kappa_s G h\,\frac{h^2}{h^2+\alpha h_K^2},\quad \kappa_s=\tfrac56,\ \alpha=0.1,$$

where $h_K$ is the longest edge. This rank-sufficient linear shear (the comment notes a pure 2-DOF constant-$\gamma$ DSG-style shear would leave one spurious zero-energy mode) recovers Kirchhoff thin-plate behavior as $h\to0$. Mass is lumped identically to DKT, and Mindlin uses the true material $\nu$. Dispatch is by plate_is_thick: thickness/span $\ge$ kThickShearRatio $=0.10$.

4. Marguerre shallow shell (shell_element_matrices)

15-DOF (5/node: $u_x,u_y,w,\theta_x,\theta_y$). It composes the CST membrane (6 DOF) + DKT or Mindlin bending (9 DOF) block-diagonally (scatter maps kCstToShell,kDktToShell), then adds Marguerre bending-stretching coupling from a per-node height field $z(x,y)$. With constant element slopes $\partial z/\partial x=\sum b_i z_i$, $\partial z/\partial y=\sum c_i z_i$, the linearized von-Kármán/Marguerre membrane strain gains $\varepsilon\mathrel{+}=S_z\nabla w$, giving cross-coupling $K_{mb}=A\,B_m^\top D_m S_z G_w$ (scattered symmetrically) and an extra bending stiffness $K_{bb}^{\text{ext}}=A\,G_w^\top(S_z^\top D_m S_z)G_w$ so curvature stiffens the shell. $G_w$ carries only the $w$ DOFs (CST-linear, $\theta$ zeroed) — a deliberate shallow-shell simplification.

5. Linear tetrahedron (tet_element_matrices)

3D isotropic elasticity, $N_i$ linear $\Rightarrow$ constant strain. Shape-function gradients $b_i,c_i,d_i$ come from inverting the $[1\,x\,y\,z]$ matrix; the $6\times12$ $B$ uses strain order $(\varepsilon_{xx},\varepsilon_{yy},\varepsilon_{zz},\gamma_{xy},\gamma_{yz},\gamma_{zx})$; full 3D Lamé $D$ with $\lambda=E\nu/[(1+\nu)(1-2\nu)]$, $\mu=E/2(1+\nu)$. $K_e=V\,B^\top D B$, lumped mass $\rho V/4$ on each translational DOF.

6. Euler-Bernoulli beam (beam_element_matrices)

Axial bar + Hermite cubic bending, plus a geometric stiffness from axial tension $T$ ($\tfrac{6}{5}T/L$, $T/10$, $\tfrac{2}{15}TL$, $\dots$ on the transverse/rotational DOFs) that recovers ideal-string physics $f=\tfrac{n}{2L}\sqrt{T/\mu}$ when $TL^2\gg EI$. Consistent Hermite mass (the $156,22L,54,-13L,\dots$ pattern $\times\rho AL/420$ for bending, $\rho AL/\{3,6\}$ for axial); rotated to global by $T^\top K_l T$, $T^\top M_l T$.

7. Acoustic P1 triangle (acoustic_element_matrices)

Scalar Helmholtz/wave operator for air pressure: $K_e=\int\nabla N\!\cdot\!\nabla N=\tfrac{1}{4A}(b_ib_j+c_ic_j)$ and a consistent $M_e=\tfrac{A}{12c^2}\,[\,2\ \text{on diagonal},\,1\ \text{off}\,]$, so the generalized problem $K_a p=\omega^2 M_a p$ (with $M_a\propto1/c^2$) yields cavity angular frequencies; e.g. a closed rectangular duct returns $\omega_{10}/2\pi\approx c/2L_x$ (test_acoustic_element.cpp).

Material, damping & scaling laws

Modal2D parameterizes every solid by a small MaterialParams struct ($E,\nu,\rho$ plus damping and optional orthotropy) and a thickness/tension that enter the FEM matrices linearly: stiffness scales as $K\propto E$ and mass as $M\propto\rho$. Because the modal spectrum solves $K\phi=\omega^2M\phi$, every natural frequency obeys $\omega\propto\sqrt{E/\rho}$ times a purely geometric factor, which the code realizes exactly through its CST, BCIZ-plate, and beam element matrices and which recovers the membrane, thin-plate, and ideal-string scaling laws (the last via the beam's geometric tension stiffness). Damping is injected after the solve as a per-mode ratio $\zeta_i=\zeta+\text{slope}\cdot\omega_i/(2\pi\cdot1000)$ (clamped to $[10^{-5},0.95]$), giving each oscillator a decay time $\tau_i=1/(\zeta_i\omega_i)$ and damped frequency $\omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2}$; higher modes decay faster so the timbre relaxes toward the fundamental. A discrete-monopole radiation coefficient $\alpha_i$ then weights each mode into the audio sum.
Material model and constitutive law

The material is the SI-unit struct MaterialParams (types.h:77). Isotropic defaults are steel-like: $E=200\,\mathrm{GPa}$, $\nu=0.30$, $\rho=7800\,\mathrm{kg/m^3}$, base damping $\zeta=0.008$. Geometry contributes a thickness $t$ (passed separately to the assembler) and, for 1-D beam/string elements, an axial pre-tension $T$ stored per BeamEdge together with the beam width (default $0.01\,$m).

Plane-stress membrane (CST)

The 2-D filled shapes use a constant-strain triangle. The isotropic plane-stress constitutive matrix and element stiffness are

$$\mathbf{D}=\frac{E}{1-\nu^2}\begin{bmatrix}1&\nu&0\\ \nu&1&0\\ 0&0&\tfrac{1-\nu}{2}\end{bmatrix},\qquad \mathbf{K}_e=tA\,\mathbf{B}^{\mathsf T}\mathbf{D}\,\mathbf{B},$$

with the consistent mass $\mathbf{M}_e=\tfrac{\rho tA}{12}\,(2\,\mathbf I$ on diagonal node blocks, $1\,\mathbf I$ off-diagonal$)$ (element_cst.cpp:38-56). Crucially $\mathbf K_e\propto E$ and $\mathbf M_e\propto\rho$ are exactly linear: $\nu$ and the geometry set the dimensionless shape of the spectrum, $E/\rho$ sets its absolute scale.

Orthotropy / grain

When anisotropic is true, the along-grain modulus is $E_x=E$ and across-grain $E_y=E\cdot\texttt{E\_y\_ratio}$ (wood default ratio $0.10$). The principal-axis plane-stress matrix uses the engineering Poisson symmetry $\nu_{yx}=\nu_{xy}E_y/E_x$ (with nu interpreted as $\nu_{xy}$):

$$\mathbf{D}_{\text{princ}}=\frac{1}{1-\nu_{xy}\nu_{yx}}\begin{bmatrix}E_x&\nu_{xy}E_y&0\\ \nu_{xy}E_y&E_y&0\\ 0&0&(1-\nu_{xy}\nu_{yx})G_{xy}\end{bmatrix},$$

with auto shear modulus $G_{xy}=(E_x+E_y)/\big(4(1+\nu_{xy})\big)$ (which collapses to the isotropic $E/(2(1+\nu))$ when $E_x=E_y$) unless G_xy_override$>0$. The code clamps $E_y\ge10^{-3}$ and the denominator $1-\nu_{xy}\nu_{yx}\ge10^{-6}$ to keep the inverted plane-stress form non-singular. A grain rotation $\theta=\texttt{grain\_angle\_rad}$ rotates $\mathbf D$ into the element frame via a Voigt strain-transformation $\mathbf D_{\text{loc}}=\mathbf T^{\mathsf T}\mathbf D_{\text{princ}}\mathbf T$ (element_cst.cpp:122-142; the $\theta=0$ branch skips the rotation). Mass is grain-independent (density is isotropic), so orthotropy reshapes the spectrum directionally without touching $M$.

Thin plate (BCIZ triangle / Kirchhoff)

Out-of-plane bending uses the flexural rigidity $D_b=E\,h^{3}/\big(12(1-\nu^{2})\big)$, computed in assemble_KM_plate and passed to the bending element. Note the bending element is a simplified DKT-style BCIZ (Bazeley-Cheung-Irons-Zienkiewicz) conforming thin-plate triangle, not the full Batoz DKT (see the source comment at element_dkt.cpp:6-8). Plate stiffness carries the cubic thickness dependence $K_b\propto E h^3$; the element uses a lumped mass matrix with translational entries $\propto\rho h$ and a rotary inertia term $\rho h^{3}/12$ on the $\theta_x,\theta_y$ DOFs. Thick plates auto-switch to a Mindlin (shear-deformable) element via plate_is_thick.

Ideal string via geometric tension stiffness

A 1-D beam element (Euler-Bernoulli, Hermite shape functions) has bending stiffness $\propto EI/L^3$ and axial $\propto EA/L$, with cross-section $A=t\cdot w$ and $I=t w^3/12$. Adding pre-tension $T$ contributes the geometric (stress-stiffening) matrix on the transverse/rotational DOFs, with diagonal entries $K^{g}_{vv}=\tfrac{6}{5}\tfrac{T}{L}$, $K^{g}_{\theta\theta}=\tfrac{2}{15}TL$ and couplings $\pm T/10$, $-\tfrac{1}{30}TL$ (element_beam.cpp:47-59). This is the discrete analogue of $+T\,\partial^2 w/\partial x^2$ in the string PDE, so when $TL^2\gg EI$ the bending term is negligible and the element reproduces ideal-string physics.

Physical scaling laws by dimensional analysis

Because $\mathbf K=E\,\hat{\mathbf K}(\text{geom},\nu)$ and $\mathbf M=\rho\,\hat{\mathbf M}(\text{geom})$ with $\hat{\mathbf K},\hat{\mathbf M}$ purely geometric, the Rayleigh quotient gives every eigenvalue $\lambda_i=\omega_i^2=\phi^{\mathsf T}\mathbf K\phi/\phi^{\mathsf T}\mathbf M\phi\propto E/\rho$. Hence the universal law

$$\omega_i=c_i\,\sqrt{\tfrac{E}{\rho}}\times(\text{geometry}),$$

where the dimensionless eigenvalue $c_i$ depends only on shape, boundary conditions and $\nu$. Specializing:

  • Membrane / in-plane (2-D shapes): the in-plane wave speed scales as $\sqrt{E/\rho}$ (plane-stress longitudinal speed $c=\sqrt{E/(\rho(1-\nu^2))}$), so $f\propto\frac{1}{L}\sqrt{E/\rho}$ — halving the size doubles every frequency.
  • Thin-plate bending: with $D_b=Eh^3/12(1-\nu^2)$ and areal mass $\rho h$, $f_i=\frac{c_i}{2\pi}\sqrt{D_b/(\rho h L^4)}\Rightarrow f\propto\frac{h}{L^{2}}\sqrt{\frac{E}{\rho\,(1-\nu^2)}}$. Bending frequencies are linear in thickness and inverse-square in size — the signature of plates/bells.
  • Ideal string (tension-dominated beam): $f_n=\frac{n}{2L}\sqrt{T/\mu}$ with linear mass $\mu=\rho A$. This is recovered by the beam's geometric stiffness in the limit $TL^2\gg EI$; the residual $EI$ adds inharmonicity (slightly stretched overtones, like a real piano).
  • Curvature shift (shells): the Marguerre shallow-shell solver couples membrane and bending energy, raising low modes (a dome is stiffer than a flat plate of equal $h$), so curvature shifts and reorders the spectrum without changing $E/\rho$.
Damping model

Damping is applied after the eigensolve as a diagonal modal-damping ratio — there is no global Rayleigh $\alpha\mathbf M+\beta\mathbf K$ matrix; each modal oscillator is independent. With the frequency-dependent toggle on, $\zeta_i=\zeta+\text{slope}\cdot\omega_i/(2\pi\cdot 1000)$, $\zeta_i\in[10^{-5},0.95]$, where $\omega_i$ is the angular eigenfrequency in rad/s (note res->frequencies stores $\omega=\sqrt\lambda$, not Hz, so dividing by $2\pi\cdot1000$ normalizes to "$\zeta$ added per kHz"). Defaults: $\zeta=0.008$, slope $=0.0005$. When the toggle is off the effective slope is forced to $0$ and every mode shares $\zeta$ (legacy uniform damping for A/B comparison). Each mode is a damped harmonic oscillator $\ddot q_i+2\zeta_i\omega_i\dot q_i+\omega_i^2 q_i=0$, whose impulse response $q_i(t)=A_i\,e^{-\zeta_i\omega_i t}\,\sin(\omega_{d,i}\,t)$, $\omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2}$ has an amplitude envelope decaying with

$$\tau_i=\frac{1}{\zeta_i\omega_i},\qquad T_{60,i}=\frac{\ln(1000)}{\zeta_i\omega_i}\approx\frac{6.91}{\zeta_i\omega_i}.$$

Because $\tau_i\propto 1/(\zeta_i\omega_i)$ and $\zeta_i$ itself grows with $\omega_i$, the high overtones decay doubly fast: a mode at $4\,$kHz has both a larger $\omega_i$ and a larger $\zeta_i$ than the fundamental. The audible consequence is a bright transient attack that mellows within tens of milliseconds toward a near-pure fundamental — the natural timbre evolution that uniform $\zeta$ cannot produce. The clamp $\zeta_i\le0.95$ keeps $\sqrt{1-\zeta_i^2}$ real (no NaN in the kernel) and the floor $\ge10^{-5}$ prevents undamped ringing.

Radiation / gain weighting to audio

For the 2-D (in-plane/membrane) solve, each mode's contribution to the radiated pressure is weighted by a discrete-monopole boundary-integral coefficient

$$\alpha_i=\rho_{\text{med}}\,\omega_i\sum_{j\in\partial\Omega}\big(\boldsymbol\phi_i(j)\!\cdot\!\hat{\mathbf n}_j\big)\,A_j,$$

i.e. medium density times angular frequency times the net normal-displacement volume flux summed over boundary nodes, where $\hat{\mathbf n}_j$ is the averaged outward in-plane boundary normal and $A_j$ is the half-length of the adjacent boundary segments. The two in-plane displacement components $\boldsymbol\phi_i(j)=(\phi_i[2j],\phi_i[2j{+}1])$ are projected onto $\hat{\mathbf n}_j$ (radiation.cpp:58-65); the result is normalized to $\max_i|\alpha_i|=1$. The $\omega_i$ factor encodes that, at equal displacement, faster modes radiate more (volume velocity $\propto\omega$); modes that breathe (net outward flux) radiate, modes whose normal motion cancels do not. The realtime audio sum is $p(t)=\sum_i \alpha_i\sum_k A_{i,k}\,e^{-\zeta_i\omega_i(t-t_{0,k})}\sin(\omega_{d,i}(t-t_{0,k}))$, evaluated one thread per sample on the GPU. Downstream the viewer applies (when post-processing is enabled) a master gain, a 1-pole low-pass, a $\tanh$ soft-clip, and an auto-normalizer that holds the peak near $0.9$, plus an optional noise gate.

Why $\omega$ is stored in rad/s, not Hz. Both the damping slope ($\div 2\pi\cdot1000$) and the radiation $\omega_i$ factor read res->frequencies as $\omega=\sqrt\lambda$. The slope is therefore "$\zeta$ added per kHz", and the kHz normalization is the single reason the damping formula divides by $2\pi\cdot1000$. Tests pin the closed form: test_oscillator.cpp checks $q(t)$ zeros at $t=\pi/\omega_d$, confirming the damped-frequency $\omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2}$ is built correctly.

Eigensolve & modal reduction

Modal2D reduces each assembled structural FE model to a small modal basis by solving the generalized symmetric eigenproblem $K\phi=\omega^2 M\phi$ for the lowest few-dozen modes. A size-based strategy (solve_eigenmodes, DENSE_DOF_THRESHOLD=512) dispatches between a GPU dense partial solver (cuSOLVER cusolverDnSsygvdx, float32, range-by-index, for $\le 512$ DOF) and a CPU sparse shift-invert Lanczos solver (pure Eigen, double precision, for larger systems or when the float32 dense path throws). Dirichlet boundary conditions are imposed by a symmetric penalty + row/column-zeroing pass before the solve, rigid-body modes are filtered by an angular-frequency threshold (with a count-based special case for free 3D solids), and mechanically disjoint objects are solved component-by-component and re-merged by ascending frequency so eigenvectors stay localized to a single object.
Theory

Governing eigenproblem

After FE assembly the free, undamped structural vibration problem is the generalized symmetric-definite eigenproblem

$$K\,\phi_i \;=\; \lambda_i\, M\,\phi_i,\qquad \lambda_i=\omega_i^2,$$

with $K=K^{\!\top}\succeq 0$ the global stiffness and $M=M^{\!\top}\succ 0$ the global consistent mass matrix (assembled from the full element mass $M_e$; the CST element mass is $m=\tfrac{\rho t A}{12}$ with $2m$ on same-node $2\times2$ diagonal blocks and $m$ off-diagonal — see cst_element_matrices, not lumped). The natural frequencies are $f_i=\omega_i/2\pi=\sqrt{\lambda_i}/2\pi$ and $\{\phi_i\}$ are the mode shapes. The DOF count per node is selected per solve as shell?5 : plate?3 : mixed?3 : 2: $2$ (CST membrane $u_x,u_y$), $3$ (membrane+beam with a drilling DOF, or DKT plate $w,\theta_x,\theta_y$), $5$ (Marguerre shallow shell $u_x,u_y,w,\theta_x,\theta_y$), and $3$ for the tetrahedral solid path.

Mass orthonormalization

Both solvers return eigenvectors $M$-orthonormalized,

$$\phi_i^{\!\top} M\,\phi_j=\delta_{ij},\qquad \phi_i^{\!\top} K\,\phi_j=\omega_i^2\,\delta_{ij},$$

i.e. unit generalized (modal) mass $m_i=\phi_i^{\!\top}M\phi_i=1$ and modal stiffness $k_i=\omega_i^2$. This is the normalization cuSOLVER's ?sygvdx produces for EIG_TYPE_1, and the one the Lanczos recurrence enforces explicitly via the $M$-inner product $\langle u,v\rangle_M=u^{\!\top}Mv$ (the basis $V$ is $M$-orthonormal). Downstream amplitude scaling depends on it: the strike projection (compute_strike_impulse) reads the modal participation directly from the eigenvector at the struck node — for plate/shell the raw out-of-plane $w$-DOF value $\phi_i(\text{w-DOF})$, for in-plane CST/mixed the directional projection $\phi_i\!\cdot\!\hat n$ onto the boundary normal $\hat n$ (or $+\hat y$ for interior strikes) — which is only the correct relative modal force amplitude when modal mass is unity.

Dense path (cuSOLVER, partial, float32)

For $n=\dim K\le 512$, solve_dense densifies $K,M$ to column-major float32 (lower triangle) and calls cusolverDnSsygvdx with CUSOLVER_EIG_TYPE_1 ($Kx=\lambda Mx$), CUSOLVER_EIG_MODE_VECTOR, CUSOLVER_EIG_RANGE_I requesting indices $[1,\,\min(n,\text{num\_modes}+3)]$, and CUBLAS_FILL_MODE_LOWER. Algorithmically this is the LAPACK ?sygvd/?sygvx-style reduction to standard form: Cholesky factor $M=LL^{\!\top}$, form $C=L^{-1}KL^{-\top}$, tridiagonalize and diagonalize $C$, then back-transform $\phi=L^{-\top}y$. The "+3" over-request gives slack so the rigid-body filter does not eat into the requested elastic count. float32 Cholesky is the precision weak point: the dispatcher wraps solve_dense in try/catch and treats any thrown std::exception (typically cusolverDnSsygvdx reporting a nonzero info, i.e. failed factorization on ill-conditioned fine meshes) as a signal to fall back to the sparse path.

Sparse path (shift-invert Lanczos, double)

For $n>512$ (or after a dense throw), solve_sparse runs a shift-invert Lanczos for the smallest eigenvalues. With spectral-transform operator

$$\mathrm{OP}=(K-\sigma M)^{-1}M,\qquad \sigma=10^{-4},$$

an eigenpair $(\lambda,\phi)$ of the original problem maps to an eigenpair of $\mathrm{OP}$ with eigenvalue $\mu=\dfrac{1}{\lambda-\sigma}$, so the smallest $\lambda$ become the largest, well-separated $\mu$ — the regime Lanczos converges fastest in. The shift $\sigma>0$ also regularizes the near-singular $K$ of free–free (unconstrained) models. The $M$-orthogonal Lanczos recurrence

$$\beta_j v_{j+1}=\mathrm{OP}\,v_j-\alpha_j v_j-\beta_{j-1}v_{j-1},\quad \alpha_j=\langle v_j,\mathrm{OP}\,v_j\rangle_M,$$

builds a tridiagonal $T=\mathrm{tridiag}(\beta_{j-1},\alpha_j,\beta_j)$ over a Krylov basis of size $\text{ncv}=\min(2\,\text{nev}+1,n)$, $\text{nev}=\min(\text{num\_modes}+5,\,n-1)$. Ritz values come from SelfAdjointEigenSolver on $T$; processing $\mu$ from largest to smallest, $\lambda=1/\mu+\sigma$, $\omega=\sqrt{\lambda}$, Ritz vectors $\phi=V\,S_{:,i}$. Stability measures: full reorthogonalization against all prior basis vectors each step (a single Gram–Schmidt sweep over $k\le j$ in the $M$-inner product), a fixed-seed (mt19937(42)) $M$-normalized random start vector, and lucky-breakdown handling that injects a fresh $M$-orthogonal random vector when $\beta_j<10^{-14}$. Despite the source comment naming it 'thick-restart', the implementation performs a single Krylov build of size ncv with no restart.

Rigid-body filtering and zero-energy regularization

Elastic modes are separated from rigid-body / spurious zero modes by the threshold $\omega<\texttt{rigid\_threshold}$ (default $1\,\mathrm{rad/s}$), counted into num_rigid (whole-system path only) and dropped. The free 3D solid is special-cased: modal_solve calls solve_eigenmodes(\dots, num\_modes+6, \text{rigid\_threshold}=0.0) — i.e. it disables threshold filtering for the solid entirely — then unconditionally erases the first 6 modes, because a free tet body has exactly 6 rigid modes and float32 leaves them at small but nonzero $\omega$ that an absolute threshold cannot catch reliably. The sparse solver additionally regularizes DOFs with simultaneously (near-)zero stiffness and mass — adding $\max(\varepsilon_{\max}\cdot10^{-10},10^{-10})$ to both diagonals — to keep the shift-invert factorization $\mathrm{SimplicialLDLT}(K-\sigma M)$ non-singular.

Excitation, contact & interaction

A strike at a viewport point is resolved to the nearest mesh node, projected onto the mass-orthonormal modal basis to produce a per-mode modal force $f_i=\phi_i^\top F$ (the out-of-plane $w$-DOF value for plates/shells, a contact-direction-weighted in-plane displacement for membranes, a displacement magnitude for 3D solids), and injected as a new amplitude/onset slot driving a closed-form decaying sinusoid $q_i(t)=A_i e^{-\zeta_i\omega_i t}\sin(\omega_{d,i}t)$ evaluated per-mode on the GPU. The viewer wraps this single primitive (modal_strike) in ten interaction modes (Strike, Rapid, Bow, Pluck, Sweep, Region, Blow, Bow+, Tension, Sustain) that differ only in event timing, magnitude shaping, and spatial spread. Two header-only audio voices extend the model beyond impulses: a ResonatorBank of noise-driven RBJ bandpass biquads gives a sustained tone, and a NonlinearVoice of free-ringing 2-pole resonators with control-rate pitch-glide and octave-up shimmer replaces the linear struck sound for gong/cymbal blooms.
The forced modal ODE and the strike as an initial condition

The continuous structure is discretized to the second-order system $M\ddot{u} + C\dot{u} + K u = F(t)$, where $u\in\mathbb{R}^{n_{\text{dof}}}$ are nodal DOFs. The generalized eigenproblem $K\phi_i=\omega_i^2 M\phi_i$ yields mass-orthonormal modes $\phi_i^\top M\phi_j=\delta_{ij}$, $\phi_i^\top K\phi_j=\omega_i^2\delta_{ij}$. Writing $u=\sum_i \phi_i q_i$ and left-multiplying by $\phi_i^\top$ decouples the system (with proportional/modal damping $\zeta_i$):

$$ \ddot{q}_i + 2\zeta_i\omega_i\dot{q}_i + \omega_i^2 q_i = \phi_i^\top F(t) \equiv f_i(t). $$

A strike is an impulsive point force $F(t)=\hat F\,\delta(t-t_0)$ applied at a single node in a single direction $\hat n$. The modal force is the projection $f_i = \phi_i^\top \hat F = \phi_i(\text{struck node})\cdot\hat n \cdot \text{magnitude}$. The code treats this as the new amplitude of an underdamped free response with $q_i(0)=0$, so each mode rings the closed-form decaying sinusoid

$$ q_i(t)=A_i\,e^{-\zeta_i\omega_i t}\,\sin(\omega_{d,i}\,t),\qquad \omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2}. $$

Crucially the implementation sets $A_i=f_i\cdot\text{magnitude}$ directly (project_strike, eval_single_mode); it does not divide by $\omega_{d,i}$. A rigorous unit impulse gives $\dot q_i(0^+)=f_i$, $A_i=f_i/\omega_{d,i}$; omitting that division gives high modes a flatter excitation spectrum than a true unit impulse — a deliberate timbral choice rather than a unit-consistent impulse response. Striking on a nodal line ($\phi_i\approx 0$ there) gives $f_i\approx 0$ and that mode stays silent — the physically-correct behaviour the viewer relies on (e.g. hitting a plate at its center kills antisymmetric modes).

Directional projection: the contact normal

The projected force depends on which DOF and which direction the strike couples to. compute_strike_impulse (modal_api.cpp:3531) dispatches on dofs_per_node and plate_w_dof_local:

  • In-plane (CST 2 DOF/node $u_x,u_y$; mixed 2D+beam) — the w_dof_local < 0 branch: the strike is an in-plane force projected onto a contact direction $(n_x,n_y)$ using local DOFs 0 and 1, $f_i = \phi_i^{(u_x)}n_x + \phi_i^{(u_y)}n_y$. For an interior node the direction defaults to $\hat n=(0,1)$ (a vertical tap). For a boundary node (membership tested against mesh.boundary_nodes) the direction is the outward boundary normal: the CCW boundary-loop tangent $t=(x_{\text{next}}-x_{\text{prev}})$ is rotated 90° CW, $\hat n=(t_y,-t_x)/\lVert t\rVert$ (nx=ty/tl; ny=-tx/tl), so an edge strike pushes into the material along the surface normal.
  • Plate / shell (out-of-plane $w$-DOF) — the w_dof_local >= 0 branch: a tap is purely transverse, so the force is just the single $w$ component, $f_i=\phi_i^{(w)}=\texttt{mode\_shapes[i][dofs\_per\_node*best + w\_dof\_local]}$. Here $w$ lives at local index 0 for the 3-DOF DKT plate $(w,\theta_x,\theta_y)$ and at index 2 for the 5-DOF Marguerre shell $(u_x,u_y,w,\theta_x,\theta_y)$; $(n_x,n_y)$ is irrelevant. This split matters: indexing membrane DOFs on a shell would dump tap energy into in-plane eigencontent and render as broadband noise (the explicit motivation in the source comment).
  • 3D solid (3 DOF/node): there is no 2D mesh to project a point strike onto. solid_node_impulse (modal_api.cpp:3684) weights each mode by the magnitude of its motion at the struck surface node, $f_i=\lVert\phi_i(\text{node})\rVert=\sqrt{\phi_x^2+\phi_y^2+\phi_z^2}$, then normalizes by the max so the most-excited mode is $\approx 1$. An off-body click (or a fallback) excites all modes equally via modal_strike_uniform (3668), which builds a flat $f_i=1$.

A cross-component-leakage filter runs only when n_components > 1 (compute_strike_impulse, modal_api.cpp:3626): modes with $|f_i|<0.02\max_j|f_j|$ are zeroed, so striking one of several disjoint shapes does not make the others "sing along" through numerical eigenvector leakage. Single-component meshes (e.g. a string mechanically coupled to a box) skip the filter, because there every weakly-driven mode is a legitimate joint mode.

Strike accumulation, superposition and the per-mode ring

Each mode keeps a ring of $K=6$ recent strike slots $(A_k,t_{0,k})$ (STRIKE_RING_SIZE=6, struct ModeState{A[6],t0[6],head} in oscillator.h). A new strike writes the next round-robin head slot rather than overwriting, and the rendered displacement sums all slots:

$$ q_i(t)=\sum_{k=0}^{K-1} A_{i,k}\,e^{-\zeta_i\omega_i(t-t_{0,k})}\sin\!\big(\omega_{d,i}(t-t_{0,k})\big),\quad t>t_{0,k}. $$

Without the ring, a rapid second strike would reset $t_0$ and force the previous decaying sinusoid to restart from $\sin(0)=0$, producing an audible cancellation/click. project_strike (oscillator.cu:15) skips slots with $|f_i\cdot\text{magnitude}|<0.005$ (absolute threshold) and clamps each slot to $|A|\le 50$ so a ring slot cannot blow up.

Damping model

Damping is per-mode, frequency-dependent. At solve time and on every modal_set_damping / _slope / _freq_enabled call the host rebuilds a per-mode vector $\zeta_i=\zeta_{\text{base}} + s\cdot\omega_i/(2\pi\cdot 1000\,\text{Hz})$, where the base $\zeta_{\text{base}}=\texttt{mat.zeta}$ is itself first clamped to $[0,0.999]$ (critical-damping ceiling) and each $\zeta_i$ is then clamped to $[10^{-5},0.95]$. The slope $s$ is gated by mat.zeta_freq_enabled (set to 0 when off, so every mode shares $\zeta_{\text{base}}$). High overtones therefore decay faster than the fundamental. The vector mode_zetas is uploaded to GPU d_zetas: the audio kernel audio_sum_kernel reads the per-mode $\zeta_i$. The visual decay path (VisualImpulseRing::eval) and the CPU reference eval_modes_cpu are, by contrast, called with a scalar $\zeta$, so the visual envelope uses a single damping ratio while the audio uses the full per-mode vector. The radiation coefficient $\alpha_i$ multiplies each mode's contribution to the PCM sum, $p=\sum_i\alpha_i q_i$, and a global user pitch knob freq_shift scales $\omega_i$ in the kernel.

Continuous excitation: the noise-driven ResonatorBank

An impulse cannot sustain a tone. The ResonatorBank (header-only) replaces the impulse with a continuously-driven filter bank: one RBJ constant-0 dB-peak bandpass biquad per mode, centered at $\omega_{0,i}=2\pi f_{c,i}/f_s$ (with $f_{c,i}$ clamped to $[20\,\text{Hz},\,0.45 f_s]$) and quality factor $Q_i=1/(2\zeta_i)\in[0.5,500]$, matched to the struck synth's damping so the timbre agrees. The normalized biquad ($b_1=0$) is

$$\alpha=\frac{\sin\omega_0}{2Q},\quad b_0=\frac{\alpha}{a_0},\ b_2=-\frac{\alpha}{a_0},\ a_1=\frac{-2\cos\omega_0}{a_0},\ a_2=\frac{1-\alpha}{a_0},\ a_0=1+\alpha,$$

run in Direct-Form-I (state $x_1,x_2,y_1,y_2$ per mode). All modes share one source: an LCG white-noise stream ($\texttt{rng}=\texttt{rng}\cdot1664525+1013904223$) low-passed by a 1-pole filter whose cutoff fraction (color) controls timbre, $\text{lp}_a=e^{-\pi c}$. Each mode is driven by $x=\text{drive}\cdot w_i$ where $w_i$ is the per-mode contact weight set by set_sustain_weights. render_add adds to the output and tracks per-block energy; has_energy() keeps it ringing until mean-square energy $<10^{-6}$ after the drive stops.

NonlinearVoice: pitch-glide + shimmer

The NonlinearVoice (header-only) replaces the linear struck sound for gong/cymbal blooms. Each mode is a free-ringing 2-pole resonator with poles at radius $r=e^{-\zeta_i\omega_{0,i}/f_s}$ and angle $\omega_{d,i}/f_s$, $y[n]=-a_{1,i}q_1-a_{2,i}q_2$, $a_{1,i}=-2r\cos(\omega_d/f_s)$, $a_{2,i}=r^2$, with state advanced $q_2\leftarrow q_1,\ q_1\leftarrow y$. A strike seeds the recurrence so it rings a decaying sine of amplitude $A_i=w_i\cdot\text{mag}$ (additively: $q_1{+}{=}A\,\text{seed}_1$, $q_2{+}{=}A\,\text{seed}_2$ with $\text{seed}_1=-\sin\omega_d/r$, $\text{seed}_2=-\sin 2\omega_d/r^2$). A per-mode amplitude envelope $\text{env}_i$ (peak-tracked, release ENV_REL=0.999) is the energy proxy. At control rate (every CTL=32 samples) two energy-conserving nonlinearities act on total energy $E=\sum_i\text{env}_i^2$ through a saturating factor $G=E/(E+E_{\text{ref}})$, $E_{\text{ref}}=0.25$:

  • Pitch glide: effective frequency rises with energy, all coeffs rebuilt at $\omega_i^{\text{eff}}=\omega_i(1+g\,G)$ with $g=\text{amount}\cdot\text{glide}$, so a hard strike starts sharp and glides down as it decays.
  • Shimmer cascade: with $\text{sh}=\text{amount}\cdot\text{shimmer}\cdot G$, a small fraction $\text{frac}=\min(0.04\,\text{sh},0.5)$ of each mode's energy moves to its octave-up neighbour ($\arg\min_j|\omega_j-2\omega_i|$, precomputed in target_), so energy climbs the spectrum (the cymbal "bloom"). Energy is conserved by scaling the source state by $\sqrt{1-\text{frac}}$ and injecting a ring of amplitude $\sqrt{\text{move}}$ ($\text{move}=\text{frac}\,\text{env}_i^2$) into the target's seeds.
One primitive, ten interactions. Every viewer interaction — Strike, Rapid (gated at 20 Hz), Bow (~30 Hz taps), Pluck (drag-force, $\min(\text{drag}/50,5)$), Sweep (20→2000 Hz rate), Region (radius falloff $0.3(1-d/R)$), Blow ($0.05\sin\phi$), Bow+ (stick-slip friction), and Sustain ($0.06$ continuous drive) — is the same modal_strike(res,x,y,mag) primitive differing only in event timing, magnitude shaping, and spatial spread. Mode 8 (Tension) never strikes: it is a beam-selection tool guarded by an interact_mode_==8 early-return firewall in on_mouse_click.

Modal sound synthesis & real-time audio

Modal2D synthesizes sound by reducing the FEM structure to a diagonal bank of independent damped harmonic oscillators (one per eigenmode) and summing their closed-form impulse responses sample-by-sample on the GPU. A strike is a point impulse projected onto the mass-orthonormal mode shapes (along the local outward boundary normal, or the transverse w-DOF for plate/shell layouts) to give per-mode excitation amplitudes; each mode then rings as $A_i\cdot e^{-\zeta_i\omega_i t}\cdot\sin(\omega_{d,i} t)$, scaled by a monopole radiation coefficient $\alpha_i$. Damping is a frequency-dependent per-mode $\zeta$ model (a base ratio plus a slope·ω term, an affine generalization of Rayleigh damping). Audio is produced in blocks of up to 512 samples by a CUDA kernel and delivered to the speaker through a PortAudio stereo callback that adds a post-processing chain. The processing order in the callback is: sustained-voice add → nonlinear-voice replace → 80 Hz-high-passed noise gate → 2-pole Chamberlin cavity bandpass → post chain (1-pole anti-alias LP, tanh soft-clip, peak-tracking auto-normalize) → stereo reverb. Two alternative excitation models exist: a noise-driven RBJ-bandpass resonator bank for sustained (rubbed/bowed) tones, and a state-space nonlinear voice for gong/cymbal pitch-glide and shimmer.
Theory

Modal reduction of the semi-discrete structural ODE

The FEM assembly produces the second-order system

$$M\,\ddot u(t) + C\,\dot u(t) + K\,u(t) = f(t),$$

with $u\in\mathbb{R}^{n_{\rm dof}}$. The generalized symmetric eigenproblem

$$K\phi_i = \omega_i^2\,M\phi_i,\qquad \phi_i^{\mathsf T} M\phi_j = \delta_{ij},\quad \phi_i^{\mathsf T} K\phi_j = \omega_i^2\delta_{ij}$$

is solved on the GPU by cusolverDnSsygvdx with CUSOLVER_EIG_TYPE_1 (the $K\phi=\lambda M\phi$ form), CUSOLVER_EIG_MODE_VECTOR, CUBLAS_FILL_MODE_LOWER, and CUSOLVER_EIG_RANGE_I requesting the lowest indices $il=1,\ iu=\min(n,\ \texttt{num\_modes}+3)$ (a small over-fetch so rigid/near-zero modes can be discarded). The returned eigenvalues are $\lambda_i$; the code takes $\omega_i=\sqrt{\lambda_i}$ (rad/s, clamped to $0$ for $\lambda_i\le0$) and discards modes with $\omega_i<$ rigid_threshold. For a TYPE_1 problem sygvd/sygvdx returns eigenvectors normalized so $\Phi^{\mathsf T} M\,\Phi = I$, i.e. mass-orthonormal (the code does not re-normalize). Expanding $u(t)=\sum_i \phi_i\,q_i(t)$ and left-multiplying by $\phi_i^{\mathsf T}$ diagonalizes the system into $N$ scalar SDOF oscillators (the defining step of modal sound synthesis):

$$\ddot q_i + 2\zeta_i\omega_i\,\dot q_i + \omega_i^2 q_i = \phi_i^{\mathsf T} f(t) \equiv f_i(t).$$

The damping matrix $C$ is never assembled; instead the code assumes modal (proportional) damping, assigning each oscillator a ratio $\zeta_i$ directly. This is the standard diagonal-damping assumption that makes $\Phi^{\mathsf T}C\Phi$ diagonal.

Damping model (affine / generalized-Rayleigh per-mode ζ)

Rather than the classic Rayleigh form $C=\alpha M+\beta K\Rightarrow \zeta_i=\tfrac12(\alpha/\omega_i+\beta\omega_i)$, the implementation uses an affine-in-frequency per-mode ratio:

$$\boxed{\;\zeta_i = \zeta_0 + s\,\dfrac{\omega_i}{2\pi\cdot 1000}\;}\qquad \zeta_i\in[10^{-5},\,0.95],$$

with base ratio $\zeta_0$ (mat.zeta, default $0.008$) and slope $s$ (mat.zeta_freq_slope, default $5\times10^{-4}$). The slope is gated by the zeta_freq_enabled flag (default true); setting $s=0$ recovers uniform/constant-$\zeta$ damping. $s>0$ makes high overtones decay faster, reproducing the perceptually important "bright attack, mellow tail". The $\beta$-proportional limb of Rayleigh damping makes $\zeta\propto\omega$, so the slope term is its direct analog while $\zeta_0$ plays the role of a frequency-flat floor. Note the affine form uses ordinary frequency $f_i=\omega_i/2\pi$ in the denominator, so $s$ is a per-kHz increment, not a true $\beta$.

Impulse response and synthesis sum

For a strike at $t_0$ depositing modal amplitude $A_i$, the underdamped Green's function of each oscillator is the closed-form

$$q_i(t) = A_i\,e^{-\zeta_i\omega_i (t-t_0)}\,\sin\!\big(\omega_{d,i}(t-t_0)\big),\qquad \omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2},$$

evaluated directly (no time-stepping / no recurrence in the main audio path — a resonator IIR is used only in the auxiliary voices). The radiated pressure proxy fed to the DAC is the radiation-weighted modal sum

$$p(t) = \sum_{i=1}^{N}\alpha_i\,q_i(t) = \sum_i \alpha_i \sum_{k} A_{i,k}\,e^{-\zeta_i\omega_i(t-t_{0,i,k})}\sin\!\big(\omega_{d,i}(t-t_{0,i,k})\big),$$

where $k$ indexes a small per-mode ring of recent strikes (STRIKE_RING_SIZE = 6) so overlapping strikes superpose additively instead of overwriting each other's phase origin (which would otherwise restart the sinusoid from $\sin 0=0$ and click). Slots with $A=0$ or $t\le t_{0}$ are skipped. An optional global pitch transposition multiplies every $\omega_i$ by freq_shift $=2^{\text{semitones}/12}$ (note: $\omega_d$ is computed from the shifted $\omega$ in the kernel).

Strike = impulse projected onto mode shapes

A point force of magnitude $g$ applied at world point $(x,y)$ projects onto mode $i$ via the modal participation factor. The code snaps the click to the nearest mesh node $j^\*$ and branches on the DOF layout:

  • In-plane (CST 2D / mixed 2D+beam, w_dof_local<0): $f_i = \phi_i^{(u_x)}(j^\*)\,\hat n_x + \phi_i^{(u_y)}(j^\*)\,\hat n_y$, where $\hat n$ is the strike direction. For an interior node $\hat n=(0,1)$ ("tap from above"); for a boundary node the outward normal is built from a central-difference tangent across the boundary loop, $t=(x_{\rm next}-x_{\rm prev},\,y_{\rm next}-y_{\rm prev})$, and $\hat n=(t_y,-t_x)/\lVert t\rVert$ (CCW loop → rotate tangent 90° CW).
  • Plate/shell (w_dof_local≥0): a vertical tap reads the transverse $w$-DOF directly, $f_i=\phi_i^{(w)}(j^\*)$, so the strike excites bending rather than membrane modes (the $(\hat n_x,\hat n_y)$ direction is unused).

The excitation amplitude is then $A_i = g\cdot f_i$. Because $\phi_i$ is mass-normalized, $f_i$ is exactly the modal force $\phi_i^{\mathsf T}f$ for a point impulse, i.e. the impulsive RHS that integrates to a jump in $\dot q_i$. A cross-component-leakage filter (zero out $|f_i|<0.02\max_k|f_k|$) is applied only when the mesh has $>1$ disjoint connected component, to suppress numerical cross-talk between localized eigenvectors; single-component meshes skip it so legitimate weakly-coupled joint modes survive. project_strike additionally discards $|A_i|<0.005$ and clamps $A_i\in[-50,50]$ before writing the ring slot.

Acoustic radiation coupling (discrete monopole boundary integral)

Each mode is weighted by a frequency-scaled normal-velocity surface integral (a lumped Rayleigh/monopole radiation efficiency):

$$\alpha_i = \rho_{\rm med}\,\omega_i\sum_{j\in\partial\Omega}\big(\phi_i(j)\cdot\hat n_j\big)\,A_j,\qquad \alpha_i\leftarrow \alpha_i/\max_k|\alpha_k|,$$

where $A_j$ is the boundary-segment half-length (lumped "area" in 2D) accumulated at boundary node $j$, $\hat n_j$ is the segment-averaged, re-normalized outward normal, $\phi_i(j)=(\phi_i^{(u_x)}(j),\phi_i^{(u_y)}(j))$ (this routine assumes the 2-DOF in-plane layout, indexing $\phi[2j],\phi[2j{+}1]$), and the result is normalized so $\max_i|\alpha_i|=1$. The $\rho_{\rm med}\,\omega_i$ prefactor captures the leading $\omega$-dependence of monopole radiated power and the medium-density coupling ($\rho_{\rm med}$ default $1.21\ \mathrm{kg/m^3}$).

Pipeline role

This section is the back half of the pipeline: shape → mesh → FEM assemble → eigensolve (produces $\omega_i$, mass-orthonormal $\phi_i$) → [modal synthesis] → audio/viz. It consumes the EigenResult (frequencies + mode shapes) from solve_dense, augments it at solve time with per-mode damping ratios (mode_zetas) and radiation coefficients (alphas), and turns user strikes into excitation amplitudes via mode-shape projection. The CUDA audio_sum_kernel is the real-time renderer that converts the modal state into a 44.1 kHz PCM stream, which the PortAudio callback post-processes and outputs. The same mode_states/impulse model (via the parallel vis_impulses rings) also drives the animated displacement visualization (modal_get_displacements) and the spectral-analysis panels (modal_fill_audio_snapshot), so synthesis sits at the junction of audio output and visual feedback.

Coupled systems

Modal2D implements three distinct inter-domain coupling mechanisms. (1) Structure↔air-cavity coupling solves a P1 acoustic-cavity eigenproblem alongside the structure and merges them via a reduced symmetric modal block matrix $A=\big[\begin{smallmatrix}\operatorname{diag}(\omega_s^2)&-L_r\\-L_r^\top&\operatorname{diag}(\omega_c^2)\end{smallmatrix}\big]$; per detected chamber one $L_r$ block is concatenated horizontally so chambers couple only through the shared structural basis. In the shipped v1 the cavities are sealed (all-Neumann) boxes (port_nodes is always empty) and the constant-pressure null mode is filtered at 1.5 rad/s. (2) Sympathetic resonance is a strike-time, modal-domain energy injection: a Lorentzian-weighted pair list across disjoint mesh components feeds a fraction of the struck mode's modal impulse into frequency-matched modes in other components. (3) String/beam tension coupling adds a Hermite geometric-stiffness contribution to each beam element, recovering taut-string physics; multi-body structures are joined by beam edges and resolved by a per-component eigensolve. All three are bypass-invariant when off.
Structure-air-cavity FEM coupling

The structure obeys $K_s\phi_s=\omega_s^2 M_s\phi_s$ and the air cavity obeys the acoustic Helmholtz P1 eigenproblem $K_a\psi_c=\omega_c^2 M_a\psi_c$, where for a linear (P1) triangle the element stiffness and mass are

$$K^e_{ij}=\int_{T}\nabla N_i\cdot\nabla N_j\,dA=\frac{b_ib_j+c_ic_j}{4A},\qquad M^e_{ij}=\frac{1}{c^2}\int_T N_iN_j\,dA=\frac{A}{12c^2}(1+\delta_{ij}),$$

with $b_i,c_i$ the shape-function gradient coefficients, $A$ the triangle area, and $c$ the speed of sound. This is the FEM discretization of $\nabla^2 p + (\omega/c)^2 p = 0$: $K_a$ is the discrete Laplacian, $M_a$ the $1/c^2$-weighted consistent mass. The assembly (assemble_acoustic_KM) supports pressure-release ($p=0$) Dirichlet BCs at port nodes via symmetric row/column zeroing with a unit diagonal, but in the shipped v1 port_nodes is always empty (port localization is deferred), so every detected cavity is solved with the default all-Neumann (rigid-wall, sealed-box) boundary condition. The fully-Neumann acoustic operator has a constant-pressure null mode at $\omega\approx 0$; solve_cavity_modes discards it (and the unit-diagonal port penalty mode at exactly $\omega=1$ rad/s, were it present) with a kCavityRigidThreshold = 1.5 rad/s strict floor.

Reduced coupled eigenproblem

Rather than assembling a monolithic fluid-structure system, the code projects onto the two uncoupled modal bases (truncated to $N_s$ structural and $N_c$ cavity modes) and solves the small dense symmetric problem $A\,v=\lambda\,v$ with

$$A=\begin{bmatrix}\operatorname{diag}(\omega_{s,1}^2,\dots,\omega_{s,N_s}^2) & -L_r\\[2pt] -L_r^\top & \operatorname{diag}(\omega_{c,1}^2,\dots,\omega_{c,N_c}^2)\end{bmatrix}\in\mathbb{R}^{N\times N},\;\; N=N_s+N_c,$$

and $\lambda=\omega^2$. Because $A$ is real symmetric by construction, solve_reduced_coupled uses Eigen's SelfAdjointEigenSolver; non-positive eigenvalues (from a pathological $L_r$) are dropped and the survivors re-sorted ascending. Each coupled eigenvector splits as $v=[a_s;\,a_c]$ giving the structural participation $a_s\in\mathbb{R}^{N_s}$ and cavity participation $a_c\in\mathbb{R}^{N_c}$ (returned in CoupledModes{omega,a_struct,a_cav}). Physical fields are reconstructed as $\phi^{\text{coupled}}=\sum_s a_s\phi_s$ and $p^{\text{coupled}}=\sum_c a_c\psi_c$. This is the symmetric (potential-form) reduction of the unsymmetric $(u,p)$ FSI problem, where $C=\int_\Gamma N_s\,(\mathbf n)\,N_a\,d\Gamma$ is the interface coupling operator and the modal projection $L_r=\Phi_s^\top C\,\Psi_c$ symmetrizes the reduced form.

Caveat on the implementation. Modal2D does not evaluate the interface line integral. build_reduced_coupling is a v1 node-lumped surrogate — for each cavity interface node it finds the nearest structural node, uses the structural displacement magnitude $\sqrt{u_x^2+u_y^2}$ (not the normal projection $\phi_s\!\cdot\mathbf n$) as the proxy, multiplies by the cavity pressure $\psi_c$ at that node, and accumulates. There is no edge length, Gauss weight, or outward normal — so $L_r$ is a qualitative coupling strength, not a quantitatively converged interface integral.

Mode repulsion / avoided crossing

For a single matched pair $\omega_s=\omega_c=\omega$ with scalar coupling $g=L_r(0,0)$, the $2\times2$ block $\big[\begin{smallmatrix}\omega^2 & -g\\ -g & \omega^2\end{smallmatrix}\big]$ has eigenvalues $\omega^2\pm g$, i.e. coupled frequencies $\sqrt{\omega^2-g}$ and $\sqrt{\omega^2+g}$ — the lower branch pushed down, the upper pushed up. test_cavity_couple.cpp validates exactly this with $g=0.15\,\omega^2$, checking the split midpoint against the analytic $\tfrac12(\sqrt{\omega^2-g}+\sqrt{\omega^2+g})$.

Multi-chamber coupling

Each detected chamber $k$ contributes its own $L_{r,k}\in\mathbb{R}^{N_s\times N_{c,k}}$, horizontally concatenated into a single $L_r=[L_{r,1}\,|\,L_{r,2}\,|\dots]$ with cavity frequencies stacked in detection order. The off-diagonal blocks only connect the shared structural basis to each chamber — there is no direct cavity-to-cavity term — so two sealed chambers couple only through the structure, never directly. Consequently structural per-component re-localization is skipped whenever cavity coupling is enabled (the reduced $L_r$ is built around the whole-system structural basis; re-localizing would detune it — the documented DOUBLE_BOX regression where the cavity field went silent).

Sympathetic resonance (modal-domain Lorentzian coupling)

Sympathetic resonance operates at strike time in the modal amplitude domain, not in $K/M$. build_node_components flood-fills the structure into connected components over triangle-edge plus beam-edge node adjacency; build_sympathetic_pairs assigns each mode $k$ to the component holding $\ge 70\%$ (LOC_THRESHOLD=0.70) of its in-plane eigenvector energy $\sum_j(\phi_{x,j}^2+\phi_{y,j}^2)$ (else it is labeled delocalized, $-1$, and excluded). If there is $\le 1$ component the pair list is empty. For every pair $(i,j)$ in different components a Lorentzian weight is computed from the relative frequency mismatch:

$$w_{ij}=\frac{1}{1+Q\,\big(\Delta\omega/\bar\omega\big)^2},\qquad \Delta\omega=\omega_i-\omega_j,\;\;\bar\omega=\tfrac12(\omega_i+\omega_j),$$

where $Q$ (default 50, clamped to $\ge 1$) sharpens the match window and pairs with $w_{ij}<0.02$ (WEIGHT_FLOOR) are pruned. Note $Q$ enters the denominator linearly (it is not squared), multiplying the squared relative detuning. On a strike, the projected impulse vector is augmented symmetrically, $f_j \mathrel{+}= k\,w_{ij}\,f_i$ and $f_i \mathrel{+}= k\,w_{ij}\,f_j$, with $k$ = sympathetic strength (default 0.10), accumulated into a side buffer and added in a single pass to avoid double-coupling. Energy thus flows only between near-resonant modes in mechanically disjoint bodies. The pair list is built lazily on the first strike after enabling and rebuilt when the toggle, $Q$, or strength changes. Applied identically on the visual strike path (modal_strike) and the audio strike path (modal_fill_audio).

String/beam tension coupling (geometric stiffness)

Each beam element is a 2-node Euler-Bernoulli frame element with 6 DOFs total (order $[u_1,v_1,\theta_1,u_2,v_2,\theta_2]$: axial $u$, transverse $v$, rotation $\theta$). Axial pre-tension $T$ adds a Hermite-consistent geometric stiffness on the transverse/rotational DOFs (the axial DOFs are unaffected); the local contribution added on top of the elastic bending block is

$$K_g=\begin{bmatrix}\tfrac{6}{5}\tfrac{T}{L}&\tfrac{T}{10}&-\tfrac{6}{5}\tfrac{T}{L}&\tfrac{T}{10}\\[2pt]\tfrac{T}{10}&\tfrac{2}{15}TL&-\tfrac{T}{10}&-\tfrac{1}{30}TL\\[2pt]-\tfrac{6}{5}\tfrac{T}{L}&-\tfrac{T}{10}&\tfrac{6}{5}\tfrac{T}{L}&-\tfrac{T}{10}\\[2pt]\tfrac{T}{10}&-\tfrac{1}{30}TL&-\tfrac{T}{10}&\tfrac{2}{15}TL\end{bmatrix}\quad(\text{on the }v_1,\theta_1,v_2,\theta_2\text{ block}),$$

the standard $\tfrac{T}{30L}[36,3L,-36,3L;\dots]$ Hermite geometric matrix added to the elastic bending stiffness ($12EI/L^3$, $6EI/L^2$, $4EI/L$, $2EI/L$ entries). When $TL^2\gg EI$ the geometric term dominates and the eigenfrequencies approach the ideal taut-string law $f_n=\frac{n}{2L}\sqrt{T/\mu}$, $\mu=\rho A$, so pitch is set by tension rather than bending stiffness. At $T=0$ (default) it reverts to a pure-bending beam. Element matrices are formed in local axial coordinates and rotated to global via $K_e=R^\top K_l R$.

Multi-body / jointed structures. Beams are the only mechanical link between otherwise-disjoint CST strips (beam-boxes via add_box_edge, polygonal bells, string-on-bridge instruments via add_string_to_mesh). Before the eigensolve, obj->mesh.beam_edges is cleared and repopulated with one {n0,n1} per beam so the flood-fill treats beam-joined strips as one component. When cavity coupling is off and more than one component is found, solve_eigenmodes_per_component solves each component separately, keeping mechanically-disjoint objects from blending their near-degenerate modes into shared eigenvectors.

DSP extras (reverb, nonlinear voice, sympathetic coupling, analysis)

Beyond the core FEM eigensolve and per-mode struck synthesis, Modal2D ships a layer of "DSP extras" that shape, extend, and analyze the modal sound. These comprise: (1) a final stereo reverb stage offering both algorithmic Freeverb (Schroeder lowpass-feedback comb / all-pass topology, i.e. the Schroeder-Moorer reverberator) and uniform-partitioned overlap-save FFT convolution; (2) a nonlinear struck "voice" (gong/cymbal energy-dependent pitch glide plus an octave-up shimmer cascade) implemented as a free-decay 2-pole modal bank with control-rate nonlinearities; (3) modal-domain sympathetic resonance that cross-feeds strike energy between frequency-matched modes in disjoint mesh components via a Lorentzian coupling kernel; (4) a noise-driven resonator bank of RBJ bandpass biquads for sustained/continuous excitation; and (5) a suite of audio-analysis transforms (log-frequency spectrogram, mel cochleagram, chroma, a per-(pitch-class,octave) "CQT" piano roll, plus spectral statistics and a real radix-2 FFT helper) used for visualization. A defining architectural choice is that the "spectral" views are computed analytically from the modal state (each mode rendered as a Lorentzian), not from a windowed FFT of PCM.
Theory

1. Reverb

1.1 Algorithmic (Freeverb / Schroeder-Moorer)

The algorithmic engine is a Freeverb: per output channel, $N_c=8$ parallel lowpass-feedback comb filters summed, then $N_a=4$ all-pass filters in series. The lowpass-feedback comb embeds a one-pole lowpass in the feedback path (the Moorer damping addition to Schroeder's reverberator). The implemented per-sample recursion, with delay length $D$, feedback $g$, and damping $d_1$ ($d_2=1-d_1$), is

$$ s[n] = d_2\,y[n-D] + d_1\, s[n-1], \qquad y[n] = x[n] + g\, s[n], $$

so $s[n]=(1-d_1)\,y[n-D]+d_1\,s[n-1]$. The comb peaks are spaced at $f_s/D$ Hz; the lowpass makes high frequencies decay faster (frequency-dependent $T_{60}$). The Schroeder all-pass with delay $D_a$ and fixed gain $a=0.5$,

$$ y[n] = -x[n] + w[n-D_a], \qquad w[n] = x[n] + a\, w[n-D_a], $$

has unity magnitude but dense phase dispersion. The eight comb delays $\{1116,1188,1277,1356,1422,1491,1557,1617\}$ and four all-pass delays $\{556,441,341,225\}$ are the canonical Freeverb tuning at 44.1 kHz; the right channel adds a fixed spread=23 samples per delay. Room size maps to $g=\text{roomsize}\cdot0.28+0.7\in[0.7,0.98]$, damping to $d_1=\text{damp}\cdot0.4$; input is scaled by FIXED_GAIN=0.015.

1.2 Convolution (uniform-partitioned, overlap-save)

The convolution engine realizes $y = x * h$ for a stereo IR via uniform-partitioned FFT convolution with overlap-save. The IR of length $L$ is split into $P=\lceil L/B\rceil$ partitions of $B=512$ samples; each $h_p$ is zero-padded to $N=2B=1024$ and pre-transformed $H_p=\mathrm{FFT}_N(h_p)$. Each input block forms a length-$N$ frame (previous + current block), transformed to $X_m$ and pushed into a frequency-domain delay line. The output spectrum is the partition sum

$$ Y_m = \sum_{p=0}^{P-1} H_p \odot X_{m-p}, \qquad y_m = \mathrm{IFFT}_N(Y_m), $$

and only the last $B$ samples of $y_m$ are valid (overlap-save discard of the first $B$). The unit tests verify it matches a direct convolution to $10^{-2}$ and that a unit-impulse IR is a passthrough. IR length is capped at 2 s ($\text{MAX\_IR}=44100\cdot2$).

1.3 Synthetic IR + top-level shaping

make_synthetic_ir builds a deterministic IR: an exponentially decaying ($\sim-60$ dB across the IR), low-passed, decorrelated LCG-noise tail plus early reflections at 13 ms (L) / 19 ms (R), RMS-normalized to $\approx0.25$; kinds Room 0.45 s / Hall 1.2 s / Plate 0.8 s (brighter LP) / Cathedral 2.0 s. The Reverb wrapper adds an integer pre-delay ring, a stereo width matrix ($\text{wet}_1=w\cdot0.5+0.5$, $\text{wet}_2=(1-w)\cdot0.5$ cross-mixing wet L/R), and a linear dry/wet crossfade $y=(1-m)x+m\,\tilde y$ against the un-predelayed dry input.

2. Nonlinear Voice (gong/cymbal)

Each mode is a free-decay 2-pole resonator — the homogeneous difference equation of a damped oscillator, with no numerator/per-sample input term (the mode rings from seeded history). Coefficients: $r_i=e^{-\zeta_i\omega_i/f_s}$, $\omega_{d,i}=\omega_i\sqrt{1-\zeta_i^2}/f_s$, $a_{1,i}=-2r_i\cos\omega_{d,i}$, $a_{2,i}=r_i^2$; recurrence $y[n]=-a_{1,i}y[n-1]-a_{2,i}y[n-2]$. A strike seeds $q_1\mathrel{+}=A\,\text{seed}_1$, $q_2\mathrel{+}=A\,\text{seed}_2$ with $\text{seed}_1=-\sin(\omega_d)/r$, $\text{seed}_2=-\sin(2\omega_d)/r^2$. A per-mode envelope $\text{env}_i$ is a peak/leaky-release follower of $|y|$. Two control-rate nonlinearities run every $\text{CTL}=32$ samples. With energy proxy $E=\sum_i\text{env}_i^2$ and saturating drive $G=E/(E+E_\text{ref})$, $E_\text{ref}=0.25$:

  • Pitch glide: $\omega_i^{\text{eff}}=\omega_i(1+g\,G)$, $g=\text{amount}\cdot\text{glide}$; $a_1,a_2$ recomputed (trig per mode each tick). A hard strike starts sharp and glides down.
  • Shimmer cascade: each mode $i$ transfers energy to the single octave mode $t=\arg\min_j|\omega_j-2\omega_i|$. With $\text{frac}=\min(0.5,\,0.04\cdot\text{sh})$, $\text{sh}=\text{amount}\cdot\text{shimmer}\cdot G$, the source $(q_1,q_2,\text{env})$ is scaled by $\sqrt{1-\text{frac}}$ and $\text{move}=\text{frac}\cdot\text{env}_i^2$ is injected into the target by seeding $\sqrt{\text{move}}\cdot(\text{seed}_1,\text{seed}_2)$, with $\text{env}_t\leftarrow\sqrt{\text{env}_t^2+\text{move}}$. The $\sqrt{\cdot}$ bookkeeping conserves amplitude-squared energy; energy climbs the spectrum ("bloom"). In the callback this voice zeroes and replaces the linear struck sound while it has energy.

3. Sympathetic Resonance (modal-domain Lorentzian coupling)

Cross-component sympathetic resonance applied in the modal domain at strike time, not as an audio filter. After the solve, the mesh is flood-filled into connected components (build_node_components, triangle + beam-edge adjacency). Each mode $k$ is assigned to the component with the majority of its eigenvector energy, $c(k)=\arg\max_c\sum_{j\in c}\|\phi_k(j)\|^2$, accepted only if that fraction exceeds $\text{LOC\_THRESHOLD}=0.70$ (else delocalized, excluded). The eigen-frequencies in eig.frequencies are angular ($\omega_i$ in rad/s, per the solver), so coupling is computed directly in $\omega$. For each pair $(i,j)$ in different components,

$$ w_{ij}=\frac{1}{1+Q\,(\Delta\omega/\bar\omega)^2},\qquad \Delta\omega=\omega_i-\omega_j,\ \bar\omega=\tfrac12(\omega_i+\omega_j), $$

a Lorentzian in fractional detuning, sharpness $Q$ (default 50, clamped $\ge1$). Pairs below $w<0.02$ ($\text{WEIGHT\_FLOOR}$) are dropped. At strike the impulse $f$ is cross-fed symmetrically through a separate accumulator: $\text{add}_j\mathrel{+}=k\,w_{ij}\,f_i$, $\text{add}_i\mathrel{+}=k\,w_{ij}\,f_j$, then $f\mathrel{+}=\text{add}$, $k=\text{strength}$ (default 0.10). The same coupling is wired into both the audio and visual strike paths.

4. Sustained / Continuous Excitation (resonator bank)

Each mode is an RBJ constant-0 dB-peak bandpass biquad at $\omega_0=2\pi f_i/f_s$ with $Q_i=1/(2\zeta_i)$ clamped to $[0.5,500]$. With $\alpha=\sin\omega_0/(2Q)$, $a_0=1+\alpha$:

$$ b_0=\tfrac{\alpha}{a_0},\ b_2=\tfrac{-\alpha}{a_0},\ a_1=\tfrac{-2\cos\omega_0}{a_0},\ a_2=\tfrac{1-\alpha}{a_0}, $$

run Direct-Form-I: $y[n]=b_0x[n]+b_2x[n-2]-a_1y[n-1]-a_2y[n-2]$. All modes share one filtered-noise source: an LCG white generator $r\leftarrow1664525r+1013904223$ feeding a one-pole lowpass $\text{lp}\leftarrow\alpha_n\text{lp}+(1-\alpha_n)w$, $\alpha_n=e^{-\pi c}$ ($c$ = color). Per-mode input is $\text{drive}\cdot\phi_i(\text{contact})$ from a published weight vector. While driven it sustains; on release the high-Q bandpasses ring down.

5. Analysis Transforms for Visualization

The Sound-Analysis window is fed by the analytic modal state, not a PCM FFT. Each mode is a Lorentzian line of power $p_i=|A_i|^2$ (with $A_i$ the envelope-only amplitude $\sum A\,e^{-\zeta\omega\Delta t}$, deliberately omitting $\sin(\omega_d t)$ to avoid frame-rate aliasing), center $f_i=\omega_i/2\pi$, width $W_i=\max(W_{\min},\zeta_i f_i)$, $W_{\min}=3$ Hz:

$$ S(f)=\sum_i p_i\frac{W_i^2}{(f-f_i)^2+W_i^2},\qquad S_\text{dB}(f)=10\log_{10}S(f). $$

Derived views: STFT = $S_\text{dB}$ on $N_f=512$ log-spaced bins $f_k=f_\min(f_\max/f_\min)^{k/(N_f-1)}$ (default $f_\min=1$ Hz, $f_\max=22$ kHz, user-adjustable), 512 columns; cochleagram = triangular mel filterbank ($m=2595\log_{10}(1+f/700)$) on the log-bin spectrum; chroma = fold each bin to $pc=(\mathrm{round}(12\log_2(f/440)+69))\bmod12$ and sum power; "CQT" = a chromatic re-permutation of a per-mode (pc, octave) piano-roll histogram over 9 octaves (modes binned by $\text{amp}^2$, rows re-laid as $\text{oct}\cdot12+pc$) — not a constant-Q filterbank on PCM. Spectral statistics are computed over the $\le64$ tracked-mode envelope powers (not the spectrogram bins): power-weighted centroid $\sum f p/\sum p$; flatness = geometric/arithmetic mean of the per-mode powers; power-weighted RMS inharmonicity $\sqrt{\sum_i p_i\text{cents}_i^2/\sum_i p_i}$ with $\text{cents}_i=1200\log_2(f_i/(n_i f_0))$, $f_0$ = lowest tracked mode at $\ge25\%$ of max amplitude, $\pm150$-cent outlier rejection. Separately a genuine radix-2 Cooley-Tukey FFT helper (fft_helper.h: Hann window, suggested $N=4096$) exists and is unit-tested but is not in the live panel: VizAudioFFT::compute_analytical_spectrum_ instead sums analytic Lorentzians on a linear axis ($f_k=k f_s/N$), a documented pivot away from PCM FFT.

Pipeline role

These subsystems sit at the tail and periphery of shape → mesh → assemble → eigensolve → modes → strike/synthesis → audio/viz. The nonlinear voice and resonator bank are alternative/additive synthesis voices in the audio callback that consume the same modal parameters ($\omega_i,\zeta_i$, contact weights) but replace (nonlinear voice while ringing; struck muted in sustain mode) or supplement the linear struck sound. The reverb is the terminal stereo stage and feeds the scope ring. The analysis transforms are the viz branch: they tap the modal state (read-only getters), not the audio bus, for spectrograms, chroma, the (pc,octave) "CQT" roll, and spectral statistics.

Medium visualization

An optional overlay paints the airborne pressure field radiated by the vibrating surface, turning the abstract mode shape into a visible wave pattern. It is a real-time GPU visualization — a time-harmonic boundary superposition evaluated per pixel — not a finite-difference or boundary-element acoustic simulation, and it is decoupled from the synthesized audio.
Model: a time-harmonic Kirchhoff–Huygens boundary superposition

Each boundary node of the structure is treated as an elementary radiator carrying a position $x_i$, an outward unit normal $\hat n_i$, and a normal surface velocity $v_{n,i}$ driven by that node's live modal displacement. By the Kirchhoff–Huygens principle, the field at a point $x$ is the retarded superposition of their wavelets:

$$p(x,t)=\sum_i v_{n,i}\,\sin\!\big(\omega\,(t - r_i/c)\big)\;A(r_i)\;\max(\hat d_i\!\cdot\!\hat n_i,\,0),\qquad r_i=\lVert x-x_i\rVert,\ \ \hat d_i=\frac{x-x_i}{r_i}.$$

Here $\omega$ is the dominant ringing mode's angular frequency (a single-frequency snapshot), $c=343\ \mathrm{m/s}$, the retarded phase $\omega(t-r_i/c)$ gives an outgoing wave, $A(r)=1/(0.5+3\sqrt{r})$ is a 2D geometric-spreading amplitude falloff, and the $\max(\cos\theta_i,0)$ obliquity factor makes each source radiate only into its outward half-space (a baffled, dipole-like directivity). Pixels inside the mesh are masked by a barycentric point-in-triangle test, so the field appears only in the surrounding "air".

Implementation

The field is evaluated by a single GLSL compute shader (#version 450, $16\times16$ local size, one invocation per output texel of an rgba8 image). Boundary sources live in an std430 SSBO (binding 1, a packed BSource{x,y,vn,out_nx,out_ny}) and the mesh triangles in a second SSBO (binding 2) for the interior mask; a u_src_step stride decimates sources for performance on dense boundaries. Output color is blue for $p>0$ and red for $p<0$, with $\alpha\propto|p|\cdot\texttt{exposure}$ clamped to ≈0.7, composited as an overlay and advanced by u_time. Built in App::init_gl and dispatched per frame when the medium_viz_ toggle is on.

Relation to the FEM air cavity

This overlay is distinct from the acoustic cavity solve. The P1 acoustic element (§3, §2) solves an interior Helmholtz eigenproblem for the trapped-air modes that genuinely color the sound of cavity instruments and feed the audio. The medium overlay is an exterior radiation picture for intuition only — it does not contribute to synthesis.

Optional two-way feedback

An experimental, off-by-default coupling (apply_medium_feedback) lets the radiated field push back on the structure, so a struck object can sympathetically drive a separate nearby one "through the air". It is a cross-component displacement coupling: node→component ids are flood-filled once, then each receiver accumulates a force from sources on other disjoint components with a 2D $1/\sqrt{r}$ radiation falloff. It is subsampled (≈ every fourth frame) and disabled in slow-motion, where the visual clock barely advances and the force would degenerate into a destabilizing near-DC push. It is the quiet, airborne sibling of the louder modal-domain sympathetic coupling in §9.

Honest scope. The medium overlay is a perceptual aid, not an acoustics solver: it uses a single dominant frequency, a tuned amplitude falloff rather than a calibrated Green's function, and no occlusion, reflection, or diffraction. It conveys "where the sound goes" at a glance without pretending to be a boundary-element or FDTD result.

Tuning & inverse design

Modal2D frames shape-to-pitch tuning as a sequence of derivative-free / surrogate-assisted root-finding and optimization problems over 1-2 geometric design parameters (half-width $W$, half-height $H$, or a uniform size scalar), each evaluated by a full FEM modal solve. The viewer implements a family of interchangeable search strategies behind a single phase-driven state machine in App::render() (modal_viewer/src/app/app.cpp), selected by fine_mode_: bracketing/bisection with an optional analytic Hellmann-Feynman Newton step (Fine-W / Manual-W, modes 1/6; the bisection family also covers Fine-Size, Fine-H, Fine-WH, Filter-W = modes 2/10/3/9), Gauss-Newton / minimum-norm steepest descent in log-frequency space (Fine-Grad, mode 12; tune_grad.h), Gaussian-process Bayesian optimization with Expected-Improvement (Fine-WH+ / Bayes-W, modes 7/8; gaussian_process.h), an adaptive 1D sampler with inverse-quadratic interpolation (Fine-W+, mode 4) and a multi-bracket bisection variant (Fine-WB, mode 5), plus a windowed log-log power-law fit overlay (Spectro strategy) and a toggle-gated reliability layer (spectrum verdict + plateau + watchdog; tune_verdict.h). The objective in all cases is cents-to-target, $c=1200\log_2(f/f^*)$, minimized to a user threshold (tune_threshold_cents_). Important: the HF Newton acceleration is wired ONLY to the Fine-W and Manual-W width searches (modes 1/6), not to Fine-Size/Fine-H/Fine-WH. Note: tune_predict.h (the recency-windowed power-law predictor and chromatic/scale-aware note-mask snapping) currently lives only in .git/v16scratch/ and is NOT compiled into the live build; its power-law math survives (re-implemented inline) in App::spectro_pick_axis_, and live chromatic targeting is done via a fixed diatonic semitone table.
Theory

All strategies optimize the same scalar objective. With detected (or mode-tracked) frequency $f$ and chromatic target $f^*$, the error in cents is

$$ c(f) = 1200\,\log_2\!\frac{f}{f^*}, \qquad \text{converged} \iff |c| < \tau_{\text{cents}}. $$

Targets are equal-tempered. In the default (absolute) mode $f^* = f_{\text{base}}\cdot 2^{s/12}$ with $s\in\{0,2,4,5,7,9,11,12\}$ (a fixed major-scale degree table et_semi[]) and octave base $f_{\text{base}}=261.63\cdot 2^{(\text{oct}-4)}$ Hz; in "flexible" mode (tuning_flexible_) $f_{\text{base}}$ is instead a captured anchor frequency tuning_flexible_base_hz_, so targets become scale-degree multiples of a measured pitch rather than absolute C-octave Hz. An optional drift compensation divides $f^*$ by the playback shift factor $2^{\text{semi}/12}$.

1. Bisection family (Fine-W / Fine-H / Fine-Size / Fine-WH / Manual-W / Filter-W)

These exploit the thin-plate/membrane scaling intuition $f \propto 1/L^2$ (larger $\Rightarrow$ lower pitch). The search variable $x$ (=$W$, $H$, or a size ratio) lives in a multiplicative bracket $[x_0/\beta,\,x_0\beta]$ with user factor $\beta=$ search_bracket_factor_ (clamped to $[1.05,30]$). The bracket update is monotone bisection: if $f>f^*$ set $x_{\text{lo}}\leftarrow x$, else $x_{\text{hi}}\leftarrow x$, then $x \leftarrow (x_{\text{lo}}+x_{\text{hi}})/2$. The relative-width collapse test is $(x_{\text{hi}}-x_{\text{lo}})/(x_{\text{hi}}+x_{\text{lo}})<10^{-3}$. Fine-WH (mode 3) is alternating-axis coordinate descent: bisect $W$ to collapse, switch to $H$, repeat (up to 12 rounds, each re-opening a window of ratio $0.4$--$2.5$ for rounds $\le6$ then $0.7$--$1.4$, with $\pm5\%$ jitter). On a non-converged collapse of mode 1/2/10 the search jitter-retries up to 8 times around the best-so-far (jitter halving every 4 retries).

2. Hellmann-Feynman Newton acceleration (Fine-W / Manual-W only)

For modes 1 and 6 the midpoint is replaced (when enabled and a derivative cache is available) by a Newton step using an analytic eigenfrequency sensitivity. The exact eigenvalue-perturbation (Hellmann-Feynman) result for $K\phi=\lambda M\phi$ ($\lambda=\omega^2$) with $\phi^TM\phi=1$ is $d\lambda_k/dp = \phi_k^{T}(dK/dp - \lambda_k\,dM/dp)\phi_k$. The code does NOT assume that normalization; instead it finite-differences the FULL Rayleigh quotient $\lambda(\phi)=\phi^TK\phi/\phi^TM\phi$ at the held eigenvector $\phi_k$, perturbing only node $x$-coordinates by $(1+\varepsilon)$ (equivalent to a horizontal stretch):

$$ \frac{d\lambda_k}{dW}\approx\frac{\lambda(\phi_k;K_1,M_1)-\lambda(\phi_k;K_0,M_0)}{\varepsilon W}, \qquad \frac{df_k}{dW}=\frac{1}{2\,\omega_k\,(2\pi)}\frac{d\lambda_k}{dW}, $$

with $\omega_k$ in rad/s. The Newton step is $W_{\text{next}} = W + (f^*-f)/(df/dW)$, clamped to the live bracket. Only the width derivative is computed.

3. Fine-Grad: Gauss-Newton / minimum-norm step in log space

Working in log-frequency, model $\ln f = \ln f_0 + a\,\delta\ln W + b\,\delta\ln H$ with axis elasticities $a=\partial\ln f/\partial\ln W$, $b=\partial\ln f/\partial\ln H$ recovered from two one-sided finite-difference probes (probe fraction $\delta=$ kGradProbeDelta$=0.02$):

$$ a=\frac{\ln(f_W/f_0)}{\ln(1+\delta)}, \qquad b=\frac{\ln(f_H/f_0)}{\ln(1+\delta)}. $$

The desired log change $g=\ln(f^*/f_0)$ gives an underdetermined system $a\,\delta\ln W+b\,\delta\ln H=g$; the minimum-norm (pseudo-inverse) solution — equivalently the steepest-descent direction of $\tfrac12|\ln f-\ln f^*|^2$ — is

$$ \delta\ln W = a\,k,\quad \delta\ln H = b\,k,\quad k=\frac{g}{a^2+b^2}. $$

A learning rate $\eta=$ kGradLearningRate$=0.8$ damps it, each axis is capped at $|\delta\ln\cdot|\le$ kGradMaxLogStep$=\ln 1.6$, and the multiplicative update $W\!\cdot e^{\eta a k}$, $H\!\cdot e^{\eta b k}$ is clamped to the bracket. When $a^2+b^2<10^{-9}$ (both axes inert) it falls back to thin-plate uniform scaling $x\leftarrow x\sqrt{f_0/f^*}$. For a separable power law $f=CW^pH^q$ finite differencing recovers $a=p,\,b=q$, so one undamped step would land on target.

4. Bayesian optimization (Fine-WH+ / Bayes-W)

Minimize the (optionally MAC-tracked) cost $y(W,H)=|c|$ with a GP surrogate. The prior is a zero-mean GP with separable RBF kernel

$$ k(\mathbf{x},\mathbf{x}') = \sigma_f^2\exp\!\Big(-\tfrac12\big[(\Delta x/\ell_x)^2+(\Delta y/\ell_y)^2\big]\Big). $$

The posterior at $\mathbf{x}_*$ uses $\alpha=(K+\sigma_n^2 I)^{-1}\mathbf{y}$ via an in-place float Cholesky $K+\sigma_n^2I=LL^T$:

$$ \mu(\mathbf{x}_*)=\mathbf{k}_*^T\alpha, \qquad s^2(\mathbf{x}_*)=k(\mathbf{x}_*,\mathbf{x}_*)-\mathbf{v}^T\mathbf{v},\;\; L\mathbf{v}=\mathbf{k}_*. $$

Sampling maximizes Expected Improvement over the incumbent $y_{\text{best}}$ (minimization form, with $\Phi$ via std::erfc):

$$ \text{EI}(\mathbf{x})=(y_{\text{best}}-\mu)\,\Phi(z)+s\,\phi(z), \qquad z=\frac{y_{\text{best}}-\mu}{s}. $$

Initial design is Latin-hypercube (6 seeds for 2D, 8 for 1D); thereafter EI is scanned on a $32\times32$ grid (BO_ACQ_GRID) and the argmax is sampled. Bayes-W (mode 8) locks $H$ ($\ell_y\!\to\!10^{-3}$, $H$ bracket collapsed to a point), giving an effective 1D search.

5. Spectro power-law fit

When the Spectro strategy is engaged on a bisection mode (1/2/3/10), the per-step midpoint is overridden by OLS on the tracked-mode trajectory $\{(x_i,f_i)\}$ of $\ln f = a + b\ln x$ (natural logs):

$$ b=\frac{\sum \ln x_i\ln f_i - n\,\overline{\ln x}\,\overline{\ln f}}{\sum(\ln x_i)^2 - n\,\overline{\ln x}^2}, \quad a=\overline{\ln f}-b\,\overline{\ln x}, \quad x_{\text{next}}=\exp\!\frac{\ln f^* - a}{b}. $$

It needs $\ge2$ tracked samples, rejects predictions outside the bracket, and arms a forced-bisection step on overshoot (cents sign flip). The shelved tune_predict.h::fit_powerlaw_predict is the same fit with a recency window and an $n{=}1$ thin-plate seed ($b=-2$, i.e. $x\sqrt{f/f^*}$).

6. Reliability layer

Spectrum verdict (classify_spectrum) picks, among audible-and-excited partials (audible window $[20,20000]$ Hz; excited = amp $\ge$ tune_excite_rel_floor_ $\times$ max-strike-amp), the one closest to the previously tracked partial within a $1.5\times$ ratio window (else the loudest); classifies Converged / KeepGoing / NoAudibleNote. A plateau counter stops when $|c|$ fails to improve by $0.5$c over tune_plateau_window_ ($=12$) steps, and a wall-clock watchdog (tune_solve_timeout_sec_ $=15$ s) aborts a stalled solve.

Pipeline role

This is the inverse-design / outer-loop stage that sits on top of the forward pipeline (shape → mesh → assemble K,M → generalized eigensolve → modes $f_k, \phi_k$). Each tuning iteration proposes geometric parameters ($W,H$ or size), calls build_tuning_component() to remesh and re-solve, reads back the modal spectrum (frequencies via modal_get_frequencies, strike excitation via modal_compute_strike_amplitudes, envelope amps via modal_get_mode_envelope_amplitudes), reduces it to a single tracked partial and a cents-to-target cost, and uses that to pick the next parameters. It closes the loop between the eigensolve output and the design input, ultimately producing a shape whose audible struck partial matches a chromatic target before strike/synthesis. The Hellmann-Feynman width derivative is the one place the inner FEM operators ($K, M, \phi$) are reused directly (via re-assembly + Rayleigh quotient) to compute an analytic sensitivity rather than treating the solver as a black box.

Computational strategy & performance

What makes the loop interactive: a geometry edit must remesh, re-assemble, re-solve, and resume audio within tens of milliseconds, while the synthesis thread feeds 44.1 kHz with no dropouts. Two ideas carry it — modal reduction collapses the full finite-element dynamics into a few-dozen decoupled scalar oscillators (so per-sample audio is $O(m)$, independent of mesh size), and a size-aware eigensolver puts the one expensive diagonalization on the GPU for the common small case and falls back to a sparse iterative method only when it must.
A little more FEM: from PDE to sparse (K, M)

Each physical regime starts from an elastodynamic PDE — 2D Navier elasticity for membranes, the Kirchhoff/Mindlin plate equations for bending, Marguerre shallow-shell theory for curved panels, 3D elasticity for solids. Multiplying by a test function and integrating by parts gives the weak form; discretizing the domain into triangles (or tetrahedra) and interpolating the field with low-order shape functions $N_i$ — barycentric/area coordinates $L_i$ for the membrane and solid, Batoz rotation interpolants for the DKT plate — turns each element into the small dense matrices $K_e=\int_{\Omega_e} B^\top D B\,dV$ and $M_e=\int_{\Omega_e}\rho\,N^\top N\,dV$ (§3). Because a node only shares elements with its mesh neighbours, scattering these into the global $K,M$ yields sparse, banded matrices: roughly $O(\text{elements})$ nonzeros, not $O(n^2)$.

The element order is a deliberate cost choice. Audible timbre is set by the lowest few-dozen eigenpairs, and for those, constant-strain triangles and lumped-mass plates are accurate enough (the free–free bar test lands within ~15% of the analytic axial frequency) while staying cheap to assemble and giving a tight sparsity pattern. The DOF count is $\text{nodes}\times\{2\ \text{membrane},\,3\ \text{plate/mixed},\,5\ \text{shell},\,3\ \text{solid}\}$, so a typical interactive mesh sits in the low hundreds to low thousands of DOFs.

Why modal reduction is what makes it real-time

The assembled second-order system $M\ddot q + C\dot q + K q = f$ couples every DOF. Solving the generalized eigenproblem $K\phi_i=\omega_i^2 M\phi_i$ once and changing to mass-orthonormal modal coordinates $q(t)=\sum_i \phi_i\,\eta_i(t)$ diagonalizes it into $m$ independent scalar ODEs

$$\ddot\eta_i + 2\zeta_i\omega_i\dot\eta_i + \omega_i^2\eta_i = f_i(t),\qquad f_i=\phi_i^\top f.$$

This is the whole performance trick. The expensive work — the diagonalization, $O(n^3)$ dense or $O(n\cdot\text{nnz}\cdot\text{iters})$ sparse — happens once per geometry; thereafter every audio sample is a handful of multiply-adds per mode, an $O(m)$ recurrence completely decoupled from mesh size. A 2000-DOF plate and a 200-DOF bar cost the same per sample once each is reduced to, say, 48 modes.

The fast solve: size-aware eigensolver dispatch

The lowest modes are extracted by solve_eigenmodes (§5), dispatching on DOF count. For $n\le 512$ it densifies $K,M$ to single precision and calls cuSOLVER's cusolverDnSsygvdx — Cholesky reduction $M=LL^\top$, $C=L^{-1}KL^{-\top}$, tridiagonalize-and-diagonalize, requesting only the lowest indices (a partial spectrum, not all $n$ eigenpairs). The float32 Cholesky is the precision cliff: on ill-conditioned fine meshes it throws, which is caught and routed to the sparse path. For $n>512$ (or on that fallback), a CPU shift-invert Lanczos runs with operator $\mathrm{OP}=(K-\sigma M)^{-1}M$, $\sigma=10^{-4}$: the spectral transform sends the smallest $\lambda$ to the largest, best-separated $\mu=1/(\lambda-\sigma)$ — the regime Lanczos converges fastest in — and the shift also regularizes the singular free–free $K$. One SimplicialLDLT factorization is reused across the iteration. Both paths return only the lowest 24–120 elastic modes after filtering rigid-body modes.

Keeping the UI and audio responsive
  • Async solve worker. Re-solves run on a background SolveWorker thread; the UI never blocks and audio keeps ringing the previous modal bank until the new one is swapped in atomically on completion.
  • Solve-scoped caches. Quantities that depend only on the modal result — strike-amplitude evaluation, the Strike-Map feature fields (§14), the tuning verdict — are recomputed once per result (keyed by the result pointer), never per frame.
  • Pinned tuning resolution. The inverse-design loop re-solves many times, so its meshes are pinned to a low density (segs = 12) that keeps each re-solve well under a second; the display mesh can be finer independently.
Fast inverse design (auto-tune)

The tuning search (§11) needs the sensitivity of a partial's frequency to a geometric parameter without paying for a full re-eigensolve at every probe. Two accelerators do the heavy lifting: a Rayleigh-quotient shape derivative — perturb a coordinate, re-assemble $K,M$, and read $\lambda=\phi^\top K\phi/\phi^\top M\phi$ at the stored eigenvector (a first-order, $O(\text{nnz})$ estimate that skips diagonalization, modal_compute_hf_width_derivs); and the Fine-Grad Gauss–Newton step in log-space plus the Gaussian-process Bayesian sampler, which reach the target in far fewer full solves than naive bisection.

Performance pitfall — build Release. The whole chain is dominated by the eigensolve, and a Debug build of the FEM/eigensolver runs roughly 10–50× slower. Debug makes startup, tuning, and even slider-dragging feel sluggish, and once masqueraded as a code regression for an entire debugging session. The Ninja build/ tree must be configured CMAKE_BUILD_TYPE=Release; the symptom of forgetting is global slowness, so the build type is the first thing to check.

Validation & numerical accuracy

The engine's correctness is pinned by a Catch2 suite of 36 test executables that mix closed-form analytic benchmarks against the FEM/eigensolver core with pure-logic unit tests for the DSP, tuning, and viewer helpers. The load-bearing physics benchmarks are: the free-free axial bar ($\omega=\pi c/L$, asserted to 15%), the closed/open rectangular air duct ($f_{10}=c/2L$ and $c/4L$, 6-8%), per-element matrix identities (symmetry, zero row-sum, lumped/consistent mass totals), structural regressions (flat shell $\equiv$ plate, DKT/Mindlin dispatch, exact rigid-mode counts), and energy-localization tests. The dominant error sources are first-order CST/linear-tet discretization (~6-15% on coarse meshes), the float32 dense cuSOLVER path vs the double-precision sparse Lanczos fallback (split at 512 DOF), and the identity-row penalty used for Dirichlet/port boundary conditions.
Analytic benchmarks and their asserted tolerances

Free-free longitudinal bar

A $1\,\mathrm{m}\times0.05\,\mathrm{m}$ steel bar ($E=200\,\mathrm{GPa}$, $\rho=7800\,\mathrm{kg/m^3}$, the MaterialParams defaults) is meshed at MeshResolution::MEDIUM, assembled with the 2-DOF plane-stress CST, and solved for 15 modes. The first free-free axial mode is $\omega_{\text{axial}} = \pi c/L$, $c=\sqrt{E/\rho}\approx 5064\,\mathrm{m/s}\Rightarrow\omega_{\text{axial}}\approx 15894\,\mathrm{rad/s}$. The test asserts Approx(omega_axial).epsilon(0.15) — within 15%, the stated CST accuracy. The wide tolerance reflects that constant-strain triangles overestimate stiffness; FEM frequencies converge to the exact value from above.

Closed and open rectangular acoustic cavities

Air is modelled by the scalar Helmholtz/wave operator with $K_e$ independent of $c$ and $M_e\propto 1/c^2$ (asserted directly: K2==K1, M2==M1/4 under $c{:}1\to2$). For a sealed (all-Neumann) box the analytic duct modes are $f_{mn}=\frac{c}{2}\sqrt{(m/L_x)^2+(n/L_y)^2}$, so $f_{10}=c/2L_x$. A $0.60\times0.40\,\mathrm{m}$ box ($c=340$, 48×32 grid) gives the lowest mode to epsilon(0.06) (6%, "FEM on a coarse structured mesh is slightly stiff"); a pressure-release (Dirichlet) duct gives the open-closed quarter-wave $f_1=c/4L$ to 8%. Both go through solve_cavity_modes with the $1.5\,\mathrm{rad/s}$ cavity floor.

Element-level identities

The acoustic CST on a unit right triangle is checked entry-by-entry ($K_{00}{=}1$, $K_{11}{=}K_{22}{=}0.5$, $K_{12}{=}0$), zero row sums (constant-pressure null space, margin(1e-12)), symmetric, and the consistent mass $M_e=\tfrac{A}{12c^2}[2,1]$ summing to the triangle area ($\sum M_{ij}=0.5$). The membrane CST uses the consistent mass $M_e=\tfrac{\rho t A}{12}[2I,I]$; test_fem_assembly.cpp asserts $K=K^T$ (Frobenius $<10^{-3}$), a positive mass diagonal, and $2N\times2N$ sizing — it does not test full positive-definiteness. The tet and Mindlin elements use lumped mass: test_solid.cpp asserts $\sum\mathrm{diag}(M_e)/3=\rho V$ (2%) and test_thick_plate.cpp asserts the three $w$-DOF lumped masses sum to $\rho h A$ ($10^{-5}$).

Energy localization, thick-plate, shell, solid, coupled cavity

  • Per-component localization: two disjoint 2-mass chains share a degenerate mode at $\omega=\sqrt{2k/m}=\sqrt 8$; solve_eigenmodes_per_component must return localized eigenvectors ($\min(e_0,e_1)/\max(e_0,e_1)<10^{-6}$). The converse — a connected body must ring across its extent — is checked by test_tri_diag.cpp (BELL_TRI cross-body ratio $>0.02$) and the glockenspiel isolation test.
  • Thick plate / shear: a free plate must have exactly 3 rigid modes with a clear gap ($w[3]>1$, $w[2]<10^{-2}w[3]$), proving the stabilized Mindlin element is hourglass-free; assemble_KM_plate reproduces direct DKT below $h/\mathrm{span}=0.10$ and direct Mindlin above to $10^{-6}$.
  • Shell flat-regression: at $z\equiv0$ the 15-DOF shell is block-diagonal in membrane vs bending DOFs ($<10^{-12}$) and matches assemble_KM_plate's lowest 6 bending modes within 1%; Marguerre coupling scales linearly with $z$ amplitude.
  • Solid: a free 3D cube solved with rigid_threshold=0 must show exactly 6 near-zero rigid modes (counted as $f<0.01\,f_{\max}$, since float32 leaks them to small-but-nonzero $\omega$) with the 7th genuinely elastic.
  • Coupled-cavity avoided crossing: equal $\omega=500$ and coupling $c=L_r(0,0)=0.15\,\omega^2$ split symmetrically with analytic midpoint $\tfrac12(\sqrt{\omega^2-c}+\sqrt{\omega^2+c})$ to $10^{-4}$; zero coupling reproduces uncoupled frequencies to $10^{-6}$.
  • Audio / DSP: eval_single_mode realizes $q(t)=A\,e^{-\zeta\omega t}\sin(\omega_d t)$, checked at $t=\pi/\omega_d$; envelope_db matches $20\log_{10}(|A|e^{-\zeta\omega t})$ to $0.01$-$0.1\,\mathrm{dB}$ with an exact $-80\,\mathrm{dB}$ floor; grad_wh_step recovers the elasticities of a separable power law $f=CW^pH^q$ to 0.5% in one step.
Numerical accuracy and error sources
  • Discretization order. All bulk elements are lowest order: CST, linear (4-node) tetrahedra, DKT/Mindlin triangles. Spatial convergence is $O(h^2)$ in displacement but only $O(h)$ in strain/stress, so frequencies converge slowly from above; this is why the bar tolerance is 15% at MEDIUM and the duct 6-8%. MeshResolution (default MEDIUM) is the primary convergence knob.
  • Mass formulation. Consistent mass (membrane CST, acoustic) gives an upper bound on frequencies; lumped mass (tet, Mindlin) gives a lower bound and removes rotary-inertia coupling. Mixing the two across element families is a deliberate accuracy/robustness trade.
  • Precision split. Systems with $\le 512$ DOF go to a float32 dense path (cuSOLVER Ssygvdx, RANGE_I, lower-triangular, $iu=\min(n,\,\mathrm{num\_modes}+3)$); larger systems use a double-precision sparse shift-invert Lanczos ($\sigma=10^{-4}$, SimplicialLDLT). The dense Cholesky inside Ssygvdx can fail on stiff FINE systems — solve_eigenmodes wraps solve_dense in try/catch and falls back. Float32 also smears the theoretically-zero rigid modes into $\omega\sim10^{-2}$, which is why solids filter rigid modes by count (exactly 6), not an absolute threshold.
  • Rigid-body / penalty handling. The default structural rigid floor is $\omega<1.0\,\mathrm{rad/s}$ (strict < in both paths). The sparse solver regularizes any DOF with simultaneously zero stiffness and zero mass by adding $\mathrm{reg}=\max(\varepsilon\cdot10^{-10},10^{-10})$ to both $K$ and $M$, preventing a singular shift-invert factorization. Dirichlet/port BCs use the identity-row penalty, whose $\omega=1\,\mathrm{rad/s}$ artifact forces the cavity floor to $1.5\,\mathrm{rad/s}$.
  • Heuristic constants. Several thresholds are tuned, not derived: thick-plate dispatch ratio $0.10$, dense/sparse split $512$, Lanczos shift $10^{-4}$, $\mathrm{nev}=\min(\mathrm{num\_modes}+5,n-1)$, $\mathrm{ncv}=\min(2\,\mathrm{nev}+1,n)$, cavity floor $1.5\,\mathrm{rad/s}$, audible band $[20,20000]\,\mathrm{Hz}$. The tests pin the behavioral consequences of these constants, not the constants themselves.
The identity-row penalty and its $\omega=1$ artifact. Dirichlet/port BCs are imposed by zeroing the port row/column then setting $K(n,n)=M(n,n)=1$ — cheap and symmetric, but it plants a non-physical eigenvalue at $\lambda=1$ ($\omega=1\,\mathrm{rad/s}$). The cavity rigid floor is set strictly above it ($1.5\,\mathrm{rad/s}$) so both the sealed-box constant-pressure null mode and this penalty artifact are filtered out before the first physical acoustic mode $f_{10}=c/2L$.

Recent additions

Two features layered onto the forward and inverse-design pipelines since the core engine stabilized: a per-location Strike Map that predicts and visualizes the timbre of striking each mesh node, and a toggle-gated tuning reliability layer (spectrum verdict + plateau + watchdog) that makes the auto-tune search stop deterministically. Both are pure-header, unit-tested, and zero-cost when off.
Strike Map (per-location predicted-sound heatmap)

The Strike Map turns the modal result into a spatial preview of "what does it sound like if I hit it here". It is a pure header, modal_viewer/src/app/strike_map.h (unit-tested in tests/test_strike_map.cpp), that converts the per-node strike response into four perceptual scalars. For a node with modal strike-amplitudes $a_k$ (obtained from modal_compute_strike_amplitudes, i.e. the mode-shape displacement at the struck point), audible-band frequencies $f_k$, and per-mode damping $\zeta$:

  • Loudness $= \lVert a\rVert_2$ — the Euclidean norm of the excited modal amplitudes.
  • Brightness $= \dfrac{\sum_k f_k\,|a_k|}{\sum_k |a_k|}$ — the amplitude-weighted spectral centroid.
  • Pitch $= f$ at $\arg\max_k |a_k|$ — the frequency of the most strongly excited partial.
  • Decay $= \dfrac{1}{\zeta\,\omega_\text{dom}}$ — the $1/e$ time constant of the dominant partial.

The four scalars are precomputed per mesh node once per solve (cached by result pointer, $O(\text{nodes}\times\text{modes})$) and drawn as a Gouraud-shaded colormap heatmap over the 2D mesh — a selectable layer (loudness / brightness / pitch / decay) with an opacity slider — plus a hover readout that reports the predicted note, frequency in Hz, decay, and loudness for the node under the cursor. It is 2D-only, lives on the Experimental tab, and costs nothing when the layer is off. Wiring: App::recompute_strike_map_ (cache rebuild) and App::draw_strike_map_overlay in modal_viewer/src/app/app.cpp.

Tuning reliability (spectrum verdict + watchdog)

An OFF-by-default reliability layer, gated by tune_reliability_enabled_, makes the auto-tune state machine terminate on physically meaningful conditions rather than grinding. Its core is a pure header, modal_viewer/src/app/tune_verdict.h (unit-tested), whose classify_spectrum examines the post-solve eigen-spectrum. Among modes that are both audible and excited, it tracks the partial nearest (within a $1.5\times$ ratio window) to the previous step's tracked frequency — a continuity criterion that resists mode-swaps — and otherwise falls back to the loudest partial. It emits a NoteClass $\in$ {Converged, KeepGoing, NoAudibleNote}.

When the layer is on, that tracked partial becomes the measured frequency the search uses; a plateau "no-progress" stop ends grinding bisection once the cents error stops improving, a wall-clock watchdog aborts a state machine stuck in a non-terminating state, and a NoAudibleNote verdict stops the search immediately. When the layer is off, the classic baseline behaviour is unchanged. As an aside, a perceived "slow tuning" episode once traced to a Debug build, not the algorithm — the FEM engine must be built in Release for the real-time and search workloads to perform.

Limitations & future work

A consolidated roadmap, grouped by area, merging the limitations and improvement opportunities surfaced across all seven technical sections. Each item is concrete and code-grounded; the grouping reflects where an investment would have the most leverage.

ANumerics & FEM elements

DKT thin-plate bending hardcodes $\nu=0.3$ inside the $D_b$ shape matrix (element_dkt.cpp:98) instead of the true material $\nu$; the scalar $D_b$ prefactor is correct but the $[1,\nu;\nu,1;\dots]$ coupling uses $0.3$, so plates with $\nu\ne0.3$ get slightly wrong bending coupling — and Mindlin (which uses the real $\nu$) is subtly inconsistent with DKT at the thickness/span = 0.10 dispatch boundary.
All bending/plate masses are lumped (crude rotary inertia $\rho h^3 A/36$, no rotary-inertia coupling); only CST membrane, beam, and acoustic elements use consistent mass. Replacing plate mass with consistent DKT/Mindlin mass would fix rotary-inertia-driven high-mode frequencies.
The Marguerre shell coupling uses a CST-linear $w$-gradient $G_w$ that carries only the $w$ DOFs ($\theta$ zeroed) with element-constant $\partial z/\partial x,\partial z/\partial y$ — first-order accurate only. Wiring full DKT shape-function derivatives into $G_w$ would improve deep/short-wavelength modes. Orthotropy is implemented only for the CST membrane; plate, shell-bending, and solid elements remain isotropic.
The tetrahedron is a single linear constant-strain element prone to volumetric locking as $\nu\to0.5$, with purely lumped diagonal mass; no 10-node quadratic or B-bar tet exists. The beam is Euler-Bernoulli (no Timoshenko shear), so short/thick beams are over-stiff; cross-section rotary inertia is omitted.
Mindlin's shear-stabilization $\alpha=0.1$ and the $k_{\text{ThickShearRatio}}=0.10$ dispatch threshold are heuristic, not derived; the element is a stabilized rank-sufficient linear-shear substitute rather than the provably locking-free DSG its own header comment names.

BEigensolver

The dense GPU path is single-precision (cusolverDnSsygvdx): float Cholesky of $M$ is the precision bottleneck and throws on ill-conditioned fine meshes, forcing the double-precision sparse fallback even for sub-512-DOF systems where dense would be ideal. A double-precision cusolverDnDsygvdx or a host LAPACK dsygvx fallback would remove the precision cliff and extend GPU coverage.
The sparse solver is a hand-rolled shift-invert Lanczos with full reorthogonalization ($O(n\cdot\text{ncv}^2)$) and no restart despite its "thick-restart" comment; it is CPU-only (no ARPACK/Spectra/cuSOLVER-sparse), so large meshes get no GPU acceleration. A true thick/implicit restart (or a linked library) would cut memory and cost.
Lanczos Ritz pairs are not checked against a residual tolerance — clustered/near-degenerate eigenvalues (common for symmetric shapes) can mix arbitrarily with no diagnostic. Adding $\lVert K\phi-\lambda M\phi\rVert_M$ monitoring would make accuracy explicit.
Fixed-DOF imposition uses a $10^6\cdot\max|K|$ penalty + row/col zeroing rather than true DOF elimination, conditioning $K$ poorly (artificial mode at $\omega=\sqrt{\text{penalty}}$). The rigid_threshold heuristic ($\omega<1$ rad/s) is disabled for solids in favour of dropping exactly 6 modes by count — fragile if a solid is partially constrained or numerically splits into >1 component.
Eigensolve dispatch is a hard DOF threshold (512), not a measured-cost decision; per-component solve over-allocates (each component requests up to num_modes then the union is truncated) and re-extracts sub-blocks with a per-component unordered_map rather than a precomputed permutation. No factorization caching across solves means interactive re-solves recompute from scratch.

CAudio & DSP

Radiation is a single normalized monopole boundary integral with no directivity, no frequency-dependent radiation efficiency, and no near/far-field model; it also hardcodes the 2-DOF layout, so plate/shell $w$-DOF modes get no radiation weighting. A Helmholtz-Kirchhoff/BEM transfer or precomputed radiation maps (James et al. 2006, PAT) would give faithful loudness and spatialization.
Damping is a heuristic affine-in-frequency $\zeta_i=\zeta_0+s\,\omega_i$ with hand-tuned defaults (0.008 base, 5e-4 slope), not fit to measured material loss factors and ignoring thermoelastic/radiation damping. The underdamped $\sqrt{1-\zeta^2}$ form is invalid past the 0.95 $\zeta$ ceiling — an explicit overdamped branch would be more correct at the extreme.
The struck audio sum is $O(\text{samples}\times\text{modes}\times6)$ brute force per block with no mode culling (inaudible / sub-peak modes still evaluated every sample), and every strike triggers two cudaMemcpyAsync uploads plus a per-block cudaStreamSynchronize on the real-time path. Moving the struck path to per-mode IIR recurrences (as the auxiliary voices already do) or a GPU-resident strike queue would cut cost and jitter and let mode counts scale.
The kernel is hard-capped at 512 samples/call and the engine zero-pads larger buffers, so a host requesting a larger PortAudio buffer silently loses audio past 512 samples; the cap should be lifted (tile the kernel) or asserted at stream-open. The whole audio path is hardcoded to 44.1 kHz (all comb/all-pass/cutoff tunings assume it).
Body resonance is faked with a single hand-dialed Chamberlin bandpass rather than the FEM air-cavity coupling that already exists in libmodal; wiring the coupled cavity modes into the audio sum would make body tone emerge from geometry. Sympathetic coupling is a one-shot strike-time impulse cross-feed (no continuous modal-ODE exchange), is $O(M^2)$, hardcodes 2 DOFs/node, and runs only on the point-strike branch. NonlinearVoice glide/shimmer are heuristic energy-proxy updates, not a derived geometrically-nonlinear shell model.
The reverb FFT is a scalar std::complex radix-2 rebuilt per block (no SIMD/FFTW/real-FFT) and convolution uses uniform partitions only, so long IRs pay full per-block cost (capped at 2 s). The "spectral" views (STFT, cochleagram, chroma, CQT) are analytic Lorentzian renderings of the modal state, NOT transforms of the audio output — so soft-clip, reverb, gating, and nonlinear bloom are invisible to them; a windowed STFT off the already-captured scope ring would let the viz reflect what is heard.

DTuning & inverse design

tune_predict.h (recency-windowed log-log power-law predictor with $n{=}1$ thin-plate $b{=}-2$ seed, and chromatic/scale-aware nearest-note snapping via a 12-bit pitch-class mask) is NOT in the live build — it exists only under .git/v16scratch/ (its test is also absent). Its OLS math is duplicated inline in spectro_pick_axis_, and live targeting is restricted to a hard-coded major-scale table, so scale masks and physics-informed first-step jumps are dormant. Re-merging it into a shared helper would remove duplication and restore scale-aware targeting.
The Hellmann-Feynman sensitivity supports only the plain 2D CST assembly (returns 0 for plate-bending and beam/mixed meshes, which lack retained unprojected eigenvectors), only differentiates $W$, and is wired only to modes 1/6 — so Fine-H, Fine-Size, Fine-WH, and Fine-Grad never get an analytic Newton step. Retaining unprojected eigenvectors would extend HF to shells/3D; supplying $a$ (and $b$) to Fine-Grad would cut its 3-solve-per-step cost and remove finite-difference truncation error.
Bayesian optimization uses fixed kernel hyperparameters (lengthscale ~20-25% of bracket, noise=1.0, amp=2500) rather than marginal-likelihood maximization; EI is brute-forced on a $32\times32$ grid (resolution-limited, does not scale beyond 2D); and the GP Cholesky is single-precision with only fixed jitter (clustered samples can make $K$ indefinite → prior fallback). Type-II ML hyperparameters, multi-start L-BFGS on EI, and conditioning-adaptive (or double) precision would each help.
Mode tracking across iterations is largely heuristic (greedy nearest-log-freq in Spectro; $1.5\times$ window in the verdict; MAC only in BO). Unifying on MAC-based tracking everywhere would reduce the mode-swap artifacts the IQI/bracket logic spends effort guarding against. Convergence guarantees are weak — many paths use magic constants (8 retries, 12 rounds, 0.5c plateau slack, 30 outer steps, 15 s watchdog) rather than derived tolerances.

EMeshing & architecture

There is no true 3D Delaunay/constrained tet mesher: 3D solids are structured grids/extrusions, so non-axis-aligned features and arbitrary geometry aren't supported, and carve_tunnels only drills Z-aligned tunnels (tolerating non-manifold pinch points). The crystal-lattice path emits no quality/area refinement (pzYeQ), so triangles near concave corners can be poorly shaped, and triangulate_with_holes ignores the lattice argument entirely.
Curvature is capped at $h=0.3\,a\,R$ and $z$ is a single-valued height field, so deep shells, overhangs, and closed surfaces (true cylinders/bells) cannot be represented in the 2D-shell path, and porosity is unavailable there. scatter_holes is rejection sampling with a 4000-attempt cap that degrades silently (never guarantees the requested void fraction); hole circles use a fixed 16 segments regardless of radius.
The "CUDA-GL interop" is not interop — cuda_gl_interop.cpp just calls glBufferSubData, so displacements round-trip device→host→VBO; a real cudaGraphicsGLRegisterBuffer + map would let a kernel write straight into the VBO. The medium compute shader is a per-pixel heuristic Kirchhoff cartoon (single dominant frequency, ad-hoc falloff, $c=343$ hardcoded) that does not feed back into audio.
The build is Windows/MSBuild-specific (opengl32, comdlg32, per-machine tools.local.bat), FetchContent pulls upstream git at configure time with no pinned ImGui-docking commit and no vendored offline copies (only Triangle is in-tree), and the documented MSBuild flow references a run_cmake_configure_vs.bat that is missing from the repo — so reproducible/offline builds are fragile and the viewer's build path is not reproducible from the checked-in scripts alone.
