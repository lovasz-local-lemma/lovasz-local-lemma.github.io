<!-- Why so many -->
<div class="card">
  <h2><span class="icon">❓</span> Why 1500+ Projects?</h2>
  <p>CMake's <code>FetchContent</code> downloads each dependency's <strong>entire</strong> source tree and generates Visual Studio projects for <em>everything</em> — including examples, tests, benchmarks, and documentation targets that we never build or use.</p>
  <p style="margin-top:.5rem">The biggest culprit is <strong>Eigen</strong> — a header-only math library that ships with 1,400+ example programs, each generating its own .vcxproj. None of these are compiled during a normal build.</p>
</div>

<!-- Dependencies explained -->
<div class="card">
  <h2><span class="icon">📦</span> Dependencies Explained</h2>

  <table>
    <tr><th>Library</th><th>Version</th><th>Role</th><th>How We Use It</th></tr>
    <tr>
      <td><strong>Eigen</strong></td>
      <td>3.4+</td>
      <td>Linear algebra</td>
      <td>Sparse matrices (K, M), dense eigensolvers, SimplicialLDLT. <strong>Header-only</strong> — no .lib is compiled from Eigen itself.</td>
    </tr>
    <tr>
      <td><strong>CUDA Toolkit</strong></td>
      <td>12.6</td>
      <td>GPU compute</td>
      <td>cuSOLVER for dense eigenproblems, custom CUDA kernels for audio synthesis. Not fetched by CMake — system install.</td>
    </tr>
    <tr>
      <td><strong>GLFW</strong></td>
      <td>3.3+</td>
      <td>Windowing</td>
      <td>Creates the OpenGL window, handles keyboard/mouse input. Compiles to <code>glfw3.lib</code>.</td>
    </tr>
    <tr>
      <td><strong>GLAD</strong></td>
      <td>—</td>
      <td>GL loader</td>
      <td>Loads OpenGL 4.5 function pointers at runtime. Single C file → <code>glad.lib</code>.</td>
    </tr>
    <tr>
      <td><strong>Dear ImGui</strong></td>
      <td>docking</td>
      <td>User interface</td>
      <td>Toolbar, panels, mode buttons, sliders, charts. Compiled into <code>imgui_lib.lib</code> with GLFW + OpenGL3 backends.</td>
    </tr>
    <tr>
      <td><strong>PortAudio</strong></td>
      <td>—</td>
      <td>Audio output</td>
      <td>Real-time audio callback at 44.1kHz, 512-sample buffer. Compiles to <code>portaudio_static_x64.lib</code>.</td>
    </tr>
    <tr>
      <td><strong>Triangle</strong></td>
      <td>1.6</td>
      <td>2D meshing</td>
      <td>Delaunay triangulation of polygons and rings. Single C file compiled directly into <code>modal_lib</code>.</td>
    </tr>
    <tr>
      <td><strong>Catch2</strong></td>
      <td>3.x</td>
      <td>Testing</td>
      <td>Unit test framework. Only linked by <code>tests/</code> executables, not the main app.</td>
    </tr>
  </table>
</div>

<div class="card">
  <h2><span class="icon">🔗</span> Build Dependency Graph</h2>
  <p>What actually gets compiled and linked when you build <code>modal_viewer</code>:</p>

  <div style="font-family:'JetBrains Mono',monospace;font-size:.82rem;line-height:2.2;margin-top:1rem;padding:1rem;background:rgba(0,0,0,0.3);border-radius:8px;overflow-x:auto">
<span style="color:var(--accent);font-weight:700">modal_viewer.exe</span>
├── <span style="color:var(--accent3)">modal_lib.lib</span> (our FEM/audio library)
│   ├── Eigen3 <span style="color:var(--dim)">(headers only, no .lib)</span>
│   ├── CUDA::cudart, cusolver, cublas <span style="color:var(--dim)">(system)</span>
│   └── triangle.c <span style="color:var(--dim)">(compiled into modal_lib)</span>
├── <span style="color:var(--accent3)">imgui_lib.lib</span> (ImGui + backends)
├── <span style="color:var(--warn)">glfw3.lib</span> <span style="color:var(--dim)">(window/input)</span>
├── <span style="color:var(--warn)">glad.lib</span> <span style="color:var(--dim)">(OpenGL loader)</span>
├── <span style="color:var(--warn)">portaudio_static_x64.lib</span> <span style="color:var(--dim)">(audio I/O)</span>
└── <span style="color:var(--dim)">Windows: opengl32.lib, kernel32.lib, user32.lib, ...</span>
  </div>
  <p class="note" style="margin-top:.8rem">Total: 5 static libraries linked. The 1,462 Eigen projects are never compiled — Eigen is header-only. They exist because CMake generates a project for every example in Eigen's source tree.</p>
</div>

<!-- What to ignore -->
<div class="card">
  <h2><span class="icon">🙈</span> What to Ignore in the Solution</h2>
  <p>When you open <code>ModalSynth.sln</code> in Visual Studio, the Solution Explorer shows ~1500 projects. Here's what to collapse/ignore:</p>
  <table>
    <tr><th>Folder / Project</th><th>Action</th><th>Why</th></tr>
    <tr><td><code>_deps/eigen-build/</code></td><td>🔽 Collapse & ignore</td><td>1,462 examples/tests/demos. Never compiled.</td></tr>
    <tr><td><code>_deps/catch2-build/</code></td><td>🔽 Collapse</td><td>Test framework internals.</td></tr>
    <tr><td><code>_deps/*-subbuild/</code></td><td>🔽 Collapse</td><td>CMake FetchContent download helpers.</td></tr>
    <tr><td><code>ALL_BUILD</code></td><td>Ignore</td><td>Meta-target that builds everything.</td></tr>
    <tr><td><code>ZERO_CHECK</code></td><td>Ignore</td><td>Triggers CMake reconfigure if CMakeLists changed.</td></tr>
    <tr><td><code>INSTALL</code></td><td>Ignore</td><td>Install target (we don't use install).</td></tr>
    <tr><td colspan="3"><hr class="sep" style="margin:.3rem 0"></td></tr>
    <tr><td><code><strong>modal_viewer</strong></code></td><td>⭐ <strong>Set as Startup</strong></td><td>The main application.</td></tr>
    <tr><td><code><strong>modal_lib</strong></code></td><td>⭐ Core library</td><td>FEM, synthesis, meshing.</td></tr>
    <tr><td><code><strong>imgui_lib</strong></code></td><td>⭐ UI library</td><td>Dear ImGui + backends.</td></tr>
  </table>
</div>
