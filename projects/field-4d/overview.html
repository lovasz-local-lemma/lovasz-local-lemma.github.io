High-dimensional Fields & Shadow Design

Start with prescribed shadows and ask what higher-dimensional object could produce them. A 4D visual hull makes that inverse problem concrete; separate five-dimensional field explorers use the extra coordinates to create continuously changing, procedural forms.

The ideaA shadow reveals only part of an object's shape; an inverse design asks what object could produce several prescribed shadows. This project extends that question to four dimensions and separately explores slices of changing five-dimensional fields.

What to watchCompare the requested projections with the reconstructed object, or move an extra coordinate to reveal a new slice.
