This endpoint already belongs in ordinary Rive.

The native Iso node also emits Rive-compatible contour bands for both the official and enhanced renderers. This browser study adapts its zero-padded marching-squares construction and uses a small, newly authored direct-light scene. It demonstrates the real conversion and export; it is not a recording, a GPU Canvas shader, or a complete port of the native graph.

The input uses four area-light samples, an ambient approximation and a finite image grid. These are NPR tone regions, not a converged global-illumination render. Native component coloring, gradient fitting, feather, depth-of-field and arbitrary graph sources are broader than this example. During dragging a smaller grid supplies a preview; release refines it.

What exports: the current ordinary .riv drawing plays in the official runtime without this scene evaluator. Live camera and lighting changes on this page are supplied by JavaScript and are not retained by that fixed-view snapshot.
