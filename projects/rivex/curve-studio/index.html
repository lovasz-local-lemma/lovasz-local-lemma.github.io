WHAT ORDINARY RIVE RECEIVES

The drawing is still Rive.

The unmodified official Rive WebGL2 renderer draws every strand from narrow filled paths. Gold uses dense sampling; coral uses the selected budget. Their maximum sampled distance exposes approximation error. RIVX names the model and authoring experiment; official Rive is the drawing endpoint.

This .riv download stores the current drawing as filled quadrilaterals. The native editor’s spline export instead uses polylines; its Cubic Pen preserves true cubic Bézier vertices.
