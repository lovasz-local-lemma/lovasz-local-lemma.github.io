rive_gl_player · architecture

RIV — Project Structure

A Rive player and from-scratch vector editor built on the official Rive runtime for parsing, scene and animation — but rendering through our own ground-up GL pipeline that implements every Rive render interface.

121 source files ~40k lines 2 renderers · ours ∥ official 5 GL-free test suites CMake · OpenGL · Dear ImGui

01Official vs Ours — the central idea

The official runtime in external/rive-runtime/ owns the file format, the object model and animation. Drawing happens through an abstract interface seam — and we provide a second, independent implementation of that seam. Same .riv, two renderers.

rive-runtime · official (external/rive-runtime)

Everything above the renderer is shared and unmodified.

.riv parser — rive::File::import Core model — Artboard · Shape · Path · Fill · Gradient · Text · Image Animation + State machines — advanceAndApply

official renderer — Rive Renderer (PLS)

rive::RiveRenderer over rive::gpu::RenderContextGLImpl (Pixel Local Storage GPU renderer, linked as rive_pls_renderer). Wrapped by gl_backend.cpp. Fast, analytic edges, flattens splines.

not cg_renderer — that is Rive's Apple CoreGraphics path, unused here

ours — GL stencil-then-cover

GlStencilShapeRenderer + SimpleShapeFactory + the Simple* render objects. A from-scratch GL pipeline: MSAA edges, analytic erf feather, exact spline primitives, in-shader gradients.

render/ · gl_shape_renderer · gl_stencil_renderer · shape_geometry

Import a .riv with SimpleShapeFactory → the artboard builds our render objects → artboard->draw(ours) runs our GL pipeline. The same scene also imports with the official factory for the live A/B compare.

02The interface seam — what "ours" implements

We reimplement rendering ground-up. We do not reimplement parsing, the Core model, or animation — those stay official and call into our objects.

rive interface (the API)our implementationrole
rive::FactorySimpleShapeFactorybuilds the render objects the runtime needs
rive::RendererGlStencilShapeRenderersave/clip/drawPath/drawImage — the GL pipeline
rive::RenderPathSimpleRenderPathgeometry: contours, fill rule, exact curves
rive::RenderPaintSimpleRenderPaintfill/stroke, gradients, feather, blend
rive::RenderShaderSimpleRenderShaderlinear/radial gradient stops
rive::RenderBufferSimpleRenderBuffervertex/index data for meshes
rive::RenderImageSimpleRenderImagedecoded bitmaps → GL textures

05The ours-only container — .rivx

Our editor and effect stacks can express things official .riv cannot (exact splines, anisotropic splats, a serialized effect/beam/space-time pipeline). Those persist in our experimental .rivx format, read and written only by the ours path.
