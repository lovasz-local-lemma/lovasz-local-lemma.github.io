Why this belongs here: Rive supplies real vector controls, the complex orbit and the time-path drawing. They share coordinates with the GPU image, without reading pixels back. This makes a mathematical family into an instrument.

Could GPU Canvas do this? Yes, with an appropriate data path: the drawing is a fragment shader plus native Rive paths, and the finite prism calculation can be ported to a supported script/shader route. This host currently supplies a CPU-traced light profile through its own storage buffer; that binding is not a drop-in GPU Canvas document. It is not an exclusive RIVX effect. The running version is an ordinary .riv interface plus a WebGPU host; putting the updated shader and interaction inside a signed .riv is a separate packaging step. Rive’s shader and uniform model ↗

From the high-dimensional field project: a Julia family has four real coordinates: two for the starting point z, two for c. Time walks a smooth closed path through the c plane; W offsets that path. Tilt couples screen position to time. This is a small sectioning experiment related to High-dimensional Fields & Shadow Design, not a port of its 5D volume renderer. That project uses compute passes; this garden needs only a fragment pass.

What runs here: a script-free Rive interface, JavaScript gestures and an external WebGPU renderer. This host preview needs no Rive script signing. An all-in-one signed document for these new time-section controls is not shipped here.

The Julia field uses z(n+1) = z(n)² + c. Its native vector diagram follows the same parameter without reading pixels from the GPU. The prism’s desk spectrum traces 25 wavelengths through a finite equilateral glass cross-section, with Snell refraction, Fresnel loss and up to six internal reflections. A narrow collimated beam follows the prism’s position while its direction stays fixed. Only rays reaching the desk contribute. Secondary Fresnel-reflected branches are omitted; total internal reflection stays in the traced path. Its 1D receiver is reconstructed with a small footprint; RGB display and faint ray guides are illustrative. The dispersion control scales SCHOTT N-SF11’s measured dispersion around the reference index; 1.00 is the catalog curve. The bevel and view through the other glass objects remain designed image mappings, not a full spectral renderer. The coherent fiber faceplate instead relays its input image to a raised output face, sampled as visible fibers. This TV-stone-inspired element is an ideal image relay; it does not simulate the complete scattering of natural ulexite. Use Reset inside the instrument to restore its original composition.
