The signed file is self-hosted and does not contact the signing service during playback. No visitor login is required. The CLI export retains Rive’s watermark. Signing enables compatible runtimes; it does not add support to older runtimes or unsupported devices.

Choose the bundle when an application already owns its renderer, custom data or browser libraries. Choose GPU Canvas when the visual instrument should travel together inside Rive. Both are supported delivery routes in this project; these paired studies demonstrate selected exports, rather than a converter for every possible Rive document. The optical model is the same in either package.

The same scene equations run through different graphics backends. The host compiler guards negative bases of even powers to avoid WebGPU NaNs; other rasterization and precision differences remain measurable. Control materials are composed for each instrument: Liquid spring in Material Nocturne and Resonant Membrane, and Constructive geometry in Spectral Observatory. Native Rive supplies labels and interaction geometry. The membrane phase follows official runtime advance events; the other studies expose their clock through data binding.
