GPU CANVAS .RIV

More than a shader in a rectangle.

The text, buttons, listeners, data bindings, animation and vector diagrams are Rive content. Embedded shaders draw the scene and expressive control materials through official GPU Canvas. The membrane also exposes its modal parameters to an optional browser audio synthesizer, enabled through its native Listen button.

Original studies authored with the official Rive CLI. These are standalone visual .riv experiments, separate from the desktop RIVX exporter. The signed CLI exports retain Rive’s watermark.

Two formats, different strengths

This project demonstrates both a packaged GPU Canvas .riv and an ordinary .riv interface delivered with a GPU host. The first keeps visual logic and shaders in the document. The second keeps the interface portable while the host supplies rendering, buffers and integrations. Material, spectral, membrane and liquid studies have both versions; Prismatic Garden uses the host format here.
