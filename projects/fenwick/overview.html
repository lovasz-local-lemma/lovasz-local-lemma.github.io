Fenwick trees

A Fenwick tree explained through the ranges it stores. Follow prefix queries and updates through an array, then extend the bookkeeping to range operations and two dimensions, with intermediate state showing why each jump is useful.

The ideaA Fenwick tree stores carefully chosen partial sums so totals and updates can be computed without revisiting every array entry. This visualization reveals the intervals behind its index jumps, including range operations and two-dimensional variants.

What to watchFollow which stored intervals a query combines and which entries an update must change.
