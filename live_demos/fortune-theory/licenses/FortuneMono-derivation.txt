Fortune Mono Medium is a static weight-500 instance derived from the bundled
SourceCodePro-wght.ttf, Copyright 2010, 2012 Adobe Systems Incorporated.

The original font's default variable axis is weight 200 (ExtraLight). Dear
ImGui's stb_truetype renderer uses that default outline rather than selecting
the weight named by an application menu. The medium instance supplies the
actual weight-500 outlines for legible small interface text.

The derived font is renamed Fortune Mono to respect the original OFL Reserved
Font Name "Source". It remains licensed under the SIL Open Font License 1.1.
See SourceCodePro-OFL.txt for the original copyright and complete license.
The font's copyright/license/designer metadata is retained.

Reproduction: python web/prepare_fonts.py with fontTools 4.58.1.
The checked-in output is used by ordinary builds; fontTools is not a runtime
or regular-build dependency. No system font or external CDN is required.
